1. Introduction

Boyce & DiPrima Ch. 1 · Zill Ch. 1

A differential equation is a rule that ties an unknown function to its derivatives. Physics hands us these rules constantly: Newton's second law says acceleration is set by force, Kirchhoff's laws say a capacitor's voltage changes at a rate set by the current through it, and Fourier's law says heat flows down a temperature gradient. In every case we know how the system changes locally and want to know what it does globally. Solving the equation is the step from "rate of change" to "trajectory". Most of the course is a toolbox of techniques for particular equation types, plus qualitative ideas (direction fields, stability, phase portraits) for when no formula exists.

1.1 Classification

Definitions

ODE vs PDE. An ordinary differential equation (ODE) involves an unknown function of a single independent variable, e.g. \(y(t)\). A partial differential equation (PDE) involves a function of several variables and its partial derivatives, e.g. \(u(x,t)\).

Order. The order is the highest derivative that appears. \(y''' + y = 0\) is third order.

Linear vs nonlinear. An \(n\)th-order ODE is linear if it can be written

\[ a_n(t)\,y^{(n)} + a_{n-1}(t)\,y^{(n-1)} + \cdots + a_1(t)\,y' + a_0(t)\,y = g(t), \]

i.e. \(y\) and its derivatives appear only to the first power, are not multiplied together, and are not fed into nonlinear functions. The coefficients may depend on \(t\) in any way. It is homogeneous if \(g(t) \equiv 0\).

System. Several unknown functions coupled by several equations, e.g. \(x' = f(x,y)\), \(y' = g(x,y)\).

Why linearity matters: for a linear homogeneous equation, any linear combination of solutions is again a solution (the superposition principle). That single fact is what makes linear equations solvable in a systematic way, and it is the same superposition you use in circuit analysis. Nonlinear equations generally do not obey it.

Common mistake

"Linear" refers to the unknown \(y\), not to \(t\). The equation \(t^2 y'' + e^{t} y' + (\sin t)\, y = \ln t\) is linear. The equation \(y' = y^2\) is not, and neither is the pendulum equation \(\theta'' + \sin\theta = 0\) or anything containing \(y\,y'\).

Example 1.1

Classify each equation by type (ODE/PDE), order, and linearity: (a) \(y'' + 3t\,y' + y = \cos t\); (b) \(u_t = k\,u_{xx}\); (c) \(y' = y^2 - t\); (d) \(y''' + \sin y = 0\); (e) \(L\,q'' + R\,q' + q/C = E_0 \cos \omega t\).

Show solution

(a) ODE, second order, linear (the coefficient \(3t\) is allowed to depend on \(t\)), nonhomogeneous.

(b) PDE (the unknown \(u\) depends on \(x\) and \(t\)), second order (from \(u_{xx}\)), linear and homogeneous. This is the heat equation.

(c) ODE, first order, nonlinear because of \(y^2\).

(d) ODE, third order, nonlinear because \(y\) sits inside \(\sin\).

(e) ODE, second order, linear with constant coefficients, nonhomogeneous: the series RLC circuit driven by a sinusoidal source.

1.2 Solutions and initial value problems

Definition

A solution of an \(n\)th-order ODE on an interval \(I\) is a function \(\phi(t)\) with \(n\) derivatives on \(I\) that satisfies the equation identically for every \(t\) in \(I\). The interval is part of the answer.

An initial value problem (IVP) pairs an \(n\)th-order ODE with \(n\) conditions at a single point \(t_0\): \(y(t_0) = y_0,\ y'(t_0) = y_1,\ \ldots,\ y^{(n-1)}(t_0) = y_{n-1}\).

A general solution is a formula, usually containing \(n\) arbitrary constants, that captures every solution. A particular solution is one specific member, e.g. the one fixed by initial conditions.

Counting constants: integrating once introduces one constant, so an \(n\)th-order equation "should" have \(n\) of them, and \(n\) initial conditions pin them down. For a first-order equation, the general solution is a one-parameter family of curves; the initial condition picks the curve through \((t_0, y_0)\).

Study tip

Checking a proposed solution is always cheap: differentiate and substitute. Do it on every exam problem where time allows. It catches sign errors that are otherwise invisible.

Example 1.2

Show that \(y = C e^{-2t} + t - \tfrac12\) solves \(y' + 2y = 2t\) for every constant \(C\), then find the solution with \(y(0) = 1\).

Show solution

Differentiate: \(y' = -2C e^{-2t} + 1\). Substitute:

\[ y' + 2y = \left(-2Ce^{-2t} + 1\right) + \left(2Ce^{-2t} + 2t - 1\right) = 2t. \;\checkmark \]

The \(C\) terms cancel, so the identity holds for all \(C\) and all \(t\). Apply the initial condition: \(y(0) = C - \tfrac12 = 1\), so \(C = \tfrac32\) and

\[ y(t) = \tfrac32 e^{-2t} + t - \tfrac12, \qquad -\infty \lt t \lt \infty. \]

Example 1.3

For which values of \(r\) is \(y = e^{rt}\) a solution of \(y'' + y' - 6y = 0\)?

Show solution

With \(y = e^{rt}\): \(y' = re^{rt}\), \(y'' = r^2 e^{rt}\). Substituting,

\[ (r^2 + r - 6)\,e^{rt} = 0. \]

Since \(e^{rt} \neq 0\), we need \(r^2 + r - 6 = (r+3)(r-2) = 0\), so \(r = 2\) or \(r = -3\). This trick is the entire idea behind Chapter 3.

1.3 Direction fields

A first-order equation \(y' = f(t,y)\) tells you the slope of the solution curve at every point of the \(ty\)-plane, without solving anything. Drawing a short line segment of slope \(f(t,y)\) at a grid of points gives the direction field (slope field). Solution curves are the curves that are tangent to the field everywhere.

Definition

An isocline of \(y' = f(t,y)\) is a curve \(f(t,y) = c\) along which all slopes equal \(c\). The isocline \(c = 0\) (the nullcline) marks where solutions have horizontal tangents: local maxima and minima of solutions lie on it.

Example 1.4

Describe the direction field of \(y' = t - y\) using isoclines and find a straight-line solution.

Show solution

Isoclines: \(t - y = c \iff y = t - c\). These are parallel lines of slope 1. On \(y = t\) the slope is 0; on \(y = t - 1\) the slope is 1; above \(y = t\) slopes are negative, below they are positive.

The isocline with \(c = 1\) is the line \(y = t - 1\), whose own slope is 1, matching the field. So it is a solution. Check: \(y' = 1\) and \(t - y = t - (t-1) = 1\). \(\checkmark\)

Every other solution approaches this line as \(t \to \infty\) (the general solution is \(y = t - 1 + Ce^{-t}\)), which you can see from the field: above the line slopes are less than 1, so curves fall toward it; below, slopes exceed 1, so they rise toward it.

Practice problems

  1. Classify \(t^2 y'' - t y' + y = \sqrt{t}\) and \(y'\,y'' = 1\).
    Answer

    First: second-order linear nonhomogeneous ODE (an Euler equation, Ch. 5). Second: second-order nonlinear ODE (product \(y' y''\)).

  2. Verify that \(y = e^{3t}\) solves \(y'' - 2y' - 3y = 0\).
    Answer

    \(y'' - 2y' - 3y = (9 - 6 - 3)e^{3t} = 0\). \(\checkmark\)

  3. Find all \(r\) such that \(y = t^r\) solves \(t^2 y'' - 2y = 0\) for \(t \gt 0\).
    Answer

    \(t^2 \cdot r(r-1)t^{r-2} - 2t^r = (r^2 - r - 2)t^r = 0\), so \((r-2)(r+1) = 0\): \(r = 2\) or \(r = -1\).

  4. For \(y' = y(3 - y)\), where are solutions increasing? Where are their slopes zero?
    Answer

    Slope zero on the horizontal lines \(y = 0\) and \(y = 3\) (these are constant solutions). Increasing for \(0 \lt y \lt 3\); decreasing for \(y \lt 0\) and \(y \gt 3\).

  5. Show that \(y = \dfrac{1}{1 + Ce^{-t}}\) solves \(y' = y - y^2\).
    Answer

    \(y' = \dfrac{Ce^{-t}}{(1+Ce^{-t})^2}\). Also \(y - y^2 = \dfrac{(1 + Ce^{-t}) - 1}{(1+Ce^{-t})^2} = \dfrac{Ce^{-t}}{(1+Ce^{-t})^2}\). Equal. \(\checkmark\)

2. First-order equations

Boyce & DiPrima Ch. 2 (numerical methods also Ch. 8) · Zill Ch. 2–3 (numerical methods also Ch. 9)

A first-order equation \(y' = f(t,y)\) says: the rate of change of a quantity depends on time and on the quantity itself. Charge on a capacitor, salt in a tank, the temperature of a cooling object and the velocity of a falling body all fit this pattern. There is no universal solution method. Instead, you learn to recognise a handful of structures (linear, separable, exact, and a few that can be transformed into these) and the method that goes with each. When no method applies, you fall back on qualitative analysis (phase lines) and numerics (Euler's method), and the existence-uniqueness theorem tells you whether a solution is even there to find.

2.1 Linear equations: integrating factors

Standard form

A first-order linear equation in standard form is

\[ y' + p(t)\,y = g(t). \]

Always divide through by the coefficient of \(y'\) first.

Derivation. The left side \(y' + p y\) is almost the derivative of a product. Multiply the whole equation by an unknown positive function \(\mu(t)\):

\[ \mu y' + \mu p\, y = \mu g. \]

By the product rule, \((\mu y)' = \mu y' + \mu' y\). The left side equals \((\mu y)'\) exactly when \(\mu' = p\,\mu\). That is a separable equation for \(\mu\): \(\mu'/\mu = p\), so \(\ln \mu = \int p\,dt\), i.e. \(\mu = e^{\int p\,dt}\) (any antiderivative works; we drop the constant). With this choice the equation collapses to

\[ (\mu y)' = \mu g \quad\Longrightarrow\quad \mu y = \int \mu g\,dt + C. \]

Key formula

\[ \mu(t) = e^{\int p(t)\,dt}, \qquad y(t) = \frac{1}{\mu(t)}\left[\int \mu(t)\,g(t)\,dt + C\right] \]

Study tip

Don't memorise the final formula; memorise the move: "multiply by \(\mu\), recognise \((\mu y)'\), integrate." On the line after multiplying, write \((\mu y)' = \mu g\) explicitly. If you can't see that it is a product-rule derivative, \(\mu\) is wrong. The general solution always has the structure \(y = Ce^{-\int p} + y_p\): a decaying (or growing) homogeneous part plus a particular part. In circuits these are the transient and steady-state responses.

Common mistake

Forgetting the \(+C\) until after dividing by \(\mu\). The constant must be added when you integrate, so that it ends up multiplied by \(1/\mu\): \(y = t^2 + C/t^2\), not \(y = t^2 + C\). Also, \(p\) must be read from standard form: for \(t y' - 2y = t^3\), \(p = -2/t\), not \(-2\).

Example 2.1

Solve \(t\,y' + 2y = 4t^2\), \(y(1) = 2\), for \(t \gt 0\).

Show solution

Standard form: divide by \(t\): \(y' + \dfrac{2}{t}y = 4t\). So \(p = 2/t\), \(g = 4t\).

Integrating factor: \(\mu = e^{\int 2/t\,dt} = e^{2\ln t} = t^2\).

Multiply: \(t^2 y' + 2t y = 4t^3\), which is \((t^2 y)' = 4t^3\). Integrate:

\[ t^2 y = t^4 + C \quad\Longrightarrow\quad y = t^2 + \frac{C}{t^2}. \]

Initial condition: \(y(1) = 1 + C = 2 \Rightarrow C = 1\). So \(y = t^2 + t^{-2}\) on \(t \gt 0\).

Check: \(y' = 2t - 2t^{-3}\), \((2/t)y = 2t + 2t^{-3}\); sum \(= 4t\). \(\checkmark\)

Example 2.2 (transient + steady state)

Solve \(y' + y = 5\sin 2t\), \(y(0) = 0\), and identify the transient and steady-state parts.

Show solution

\(p = 1\), so \(\mu = e^{t}\) and \((e^t y)' = 5e^t \sin 2t\).

The integral (by parts twice, or the standard formula \(\int e^{at}\sin bt\,dt = \frac{e^{at}(a\sin bt - b\cos bt)}{a^2+b^2}\) with \(a=1,\ b=2\)):

\[ \int 5e^t\sin 2t\,dt = 5\cdot\frac{e^t(\sin 2t - 2\cos 2t)}{5} = e^t(\sin 2t - 2\cos 2t). \]

So \(e^t y = e^t(\sin 2t - 2\cos 2t) + C\), i.e. \(y = \sin 2t - 2\cos 2t + Ce^{-t}\).

\(y(0) = -2 + C = 0 \Rightarrow C = 2\):

\[ y(t) = \underbrace{2e^{-t}}_{\text{transient}} + \underbrace{\sin 2t - 2\cos 2t}_{\text{steady state}}. \]

Check: \(y' = -2e^{-t} + 2\cos 2t + 4\sin 2t\); adding \(y\) gives \(5\sin 2t\). \(\checkmark\) The steady state has amplitude \(\sqrt{1^2+2^2} = \sqrt5\): exactly the low-pass filter result \(|H(j\omega)| = 1/\sqrt{1+\omega^2}\) times the input amplitude 5, with \(\omega = 2\).

2.2 Separable equations

Definition

\(\dfrac{dy}{dx} = f(x)\,g(y)\) is separable: the right side factors into a function of \(x\) times a function of \(y\).

Why "separating" is legal. Divide by \(g(y)\) (where nonzero): \(\frac{1}{g(y)}\frac{dy}{dx} = f(x)\). If \(H(y)\) is an antiderivative of \(1/g\), the chain rule says the left side is \(\frac{d}{dx}H(y(x))\). Integrating both sides in \(x\) gives \(H(y) = \int f(x)\,dx + C\). The shorthand "\(dy/g(y) = f(x)\,dx\), integrate both sides" is just this chain-rule argument.

Key formula

\[ \int \frac{dy}{g(y)} = \int f(x)\,dx + C \]

Common mistake

Dividing by \(g(y)\) silently throws away every constant solution \(y = c\) with \(g(c) = 0\). For \(y' = y^2\cos t\), separating gives \(y = -1/(\sin t + C)\), which never equals 0; but \(y \equiv 0\) is also a solution. Always list the equilibria separately. Also, the result is often an implicit solution; solve for \(y\) only when you can, and state the interval on which the solution is valid.

Example 2.3 (finite-time blow-up)

Solve \(y' = x(1 + y^2)\), \(y(0) = 1\), and find the largest interval on which the solution exists.

Show solution

Separate: \(\dfrac{dy}{1+y^2} = x\,dx\). Integrate: \(\arctan y = \tfrac12 x^2 + C\).

At \(x = 0\): \(\arctan 1 = \pi/4 = C\). So \(y = \tan\!\left(\tfrac12 x^2 + \tfrac{\pi}{4}\right)\).

Interval: the tangent blows up when its argument reaches \(\pi/2\). We need \(\tfrac12 x^2 + \tfrac\pi4 \lt \tfrac\pi2\), i.e. \(x^2 \lt \pi/2\), so the solution lives on \(-\sqrt{\pi/2} \lt x \lt \sqrt{\pi/2}\) (about \(|x| \lt 1.253\)).

Check: \(y' = \sec^2(\cdot)\cdot x = x(1 + \tan^2(\cdot)) = x(1+y^2)\). \(\checkmark\) Note that \(f(x,y) = x(1+y^2)\) is perfectly smooth everywhere, yet the solution escapes to infinity at a finite \(x\). This is a purely nonlinear phenomenon; linear equations never do this.

Example 2.4

Solve \(\dfrac{dy}{dt} = \dfrac{3t^2 + 1}{2y}\), \(y(0) = -2\).

Show solution

Separate: \(2y\,dy = (3t^2+1)\,dt\). Integrate: \(y^2 = t^3 + t + C\). At \(t = 0\): \(4 = C\).

So \(y^2 = t^3 + t + 4\). Choose the branch matching \(y(0) = -2 \lt 0\):

\[ y = -\sqrt{t^3 + t + 4}. \]

Valid while \(t^3 + t + 4 \gt 0\). Since \(t^3 + t + 4\) is increasing and vanishes at \(t = -1.379\ldots\) (where \((-1.379)^3 \approx -2.62\) and \(-2.62 - 1.38 + 4 \approx 0\)), the interval is roughly \(t \gt -1.38\). At that endpoint \(y \to 0\) and \(y' = (3t^2+1)/(2y)\) blows up: the solution curve has a vertical tangent.

2.3 Modeling with first-order equations

Almost every first-order model is a balance law:

Balance principle

\[ \frac{d(\text{amount})}{dt} = (\text{rate in}) - (\text{rate out}) \]

Standard models

  • Mixing tank (volume \(V\), inflow concentration \(c_{in}\), flow rate \(r\) in and out): \(\;Q' = r\,c_{in} - \dfrac{r}{V}Q\), where \(Q\) is the amount of solute.
  • Newton's law of cooling: \(\;T' = -k(T - T_m)\), \(k \gt 0\), with solution \(T = T_m + (T_0 - T_m)e^{-kt}\).
  • RC circuit (source \(V_s\), series \(R\), \(C\)): KVL gives \(R\,i + v_C = V_s\) and \(i = C\,v_C'\), so \(\;RC\,v_C' + v_C = V_s(t)\). Time constant \(\tau = RC\).
  • RL circuit: \(\;L\,i' + R\,i = V_s(t)\). Time constant \(\tau = L/R\).
  • Falling body, linear drag (velocity down positive): \(\;m v' = mg - bv\). Terminal velocity \(v_T = mg/b\).
  • Falling body, quadratic drag: \(\;m v' = mg - cv^2\). Terminal velocity \(v_T = \sqrt{mg/c}\).

The linear models above all have the form \(y' = -\frac{1}{\tau}(y - y_\infty)\) for a constant input, with solution

Key formula (first-order step response)

\[ y(t) = y_\infty + \left(y(0) - y_\infty\right)e^{-t/\tau} \]

After one time constant the system has covered \(1 - e^{-1} \approx 63\%\) of the gap; after \(5\tau\), more than \(99\%\).

Example 2.5 (mixing)

A 100 L tank starts with pure water. Brine containing 0.2 kg of salt per litre flows in at 5 L/min, and the well-stirred mixture drains at 5 L/min. Find the salt \(Q(t)\) and the time when the tank holds 10 kg.

Show solution

Rate in \(= 5 \times 0.2 = 1\) kg/min. Rate out \(= 5 \times \frac{Q}{100} = \frac{Q}{20}\) kg/min (volume stays 100 L).

\[ Q' = 1 - \frac{Q}{20}, \qquad Q(0) = 0. \]

This is the step-response form with \(\tau = 20\) min and \(Q_\infty = 20\) kg (the tank's equilibrium: 100 L at 0.2 kg/L). Hence \(Q(t) = 20\left(1 - e^{-t/20}\right)\).

Set \(Q = 10\): \(e^{-t/20} = \tfrac12 \Rightarrow t = 20\ln 2 \approx 13.9\) min.

Example 2.6 (cooling)

A mug of coffee at 90°C sits in a 22°C room. After 5 minutes it is 70°C. When is it 40°C?

Show solution

\(T(t) = 22 + 68e^{-kt}\). At \(t = 5\): \(48 = 68 e^{-5k}\), so \(k = \frac15\ln\frac{68}{48} = \frac15\ln\frac{17}{12} \approx 0.0697\ \text{min}^{-1}\).

Set \(T = 40\): \(18 = 68e^{-kt} \Rightarrow t = \dfrac{\ln(68/18)}{k} \approx \dfrac{1.329}{0.0697} \approx 19.1\) min.

Example 2.7 (RC charging and quadratic drag)

(a) A 12 V source charges a 100 μF capacitor through 10 kΩ from \(v_C(0) = 0\). When does \(v_C\) reach 9 V?
(b) Solve \(m v' = mg - cv^2\), \(v(0) = 0\).

Show solution

(a) \(\tau = RC = 10^4 \times 10^{-4} = 1\) s, \(v_\infty = 12\). So \(v_C = 12(1 - e^{-t})\). Setting \(9 = 12(1 - e^{-t})\) gives \(e^{-t} = \tfrac14\), \(t = \ln 4 \approx 1.39\) s.

(b) Write \(v_T^2 = mg/c\). Then \(v' = \frac{c}{m}(v_T^2 - v^2) = \frac{g}{v_T^2}(v_T^2 - v^2)\). Separate with partial fractions:

\[ \int \frac{dv}{v_T^2 - v^2} = \frac{1}{v_T}\operatorname{artanh}\frac{v}{v_T} = \frac{g}{v_T^2}\,t + C. \]

\(v(0) = 0\) gives \(C = 0\), so \(\operatorname{artanh}(v/v_T) = gt/v_T\) and

\[ v(t) = v_T \tanh\!\left(\frac{g t}{v_T}\right), \qquad v_T = \sqrt{mg/c}. \]

Check: \(v' = g\,\operatorname{sech}^2(gt/v_T) = g(1 - v^2/v_T^2) = g - \frac{c}{m}v^2\). \(\checkmark\) For small \(t\), \(\tanh x \approx x\) gives \(v \approx gt\) (free fall), and \(v \to v_T\) as \(t\to\infty\).

2.4 Existence and uniqueness

Before solving, it helps to know a solution exists, that there is only one, and on what interval. Linear equations are well behaved: the solution lives as long as the coefficients are continuous. Nonlinear equations only guarantee a solution near the initial point.

Theorem (linear first-order equations)

If \(p\) and \(g\) are continuous on an open interval \(I\) containing \(t_0\), then for any \(y_0\) the IVP \(y' + p(t)y = g(t)\), \(y(t_0) = y_0\) has exactly one solution, and it exists on all of \(I\).

Theorem (nonlinear first-order equations)

Suppose \(f\) and \(\partial f/\partial y\) are continuous on an open rectangle \(\alpha \lt t \lt \beta,\ \gamma \lt y \lt \delta\) containing \((t_0, y_0)\). Then on some interval \(t_0 - h \lt t \lt t_0 + h\) contained in \((\alpha,\beta)\) there is a unique solution of \(y' = f(t,y)\), \(y(t_0) = y_0\). (Continuity of \(f\) alone guarantees existence but not uniqueness.)

Geometric consequence of uniqueness: two different solution curves can never cross or touch where the hypotheses hold. That is what lets you trap solutions between equilibria in the next section.

Common mistake

The nonlinear theorem does not tell you how big \(h\) is. Example 2.3 had a perfectly smooth \(f\) and still blew up at \(|x| = \sqrt{\pi/2}\). For linear equations you can read the interval directly from the coefficients, without solving.

Example 2.8

(a) Without solving, find the largest interval on which \((t-3)y' + (\ln t)\,y = 2t\), \(y(1) = 2\) has a unique solution.
(b) Show that \(y' = y^{1/3}\), \(y(0) = 0\) has more than one solution, and explain why the theorem doesn't forbid it.

Show solution

(a) Standard form: \(y' + \dfrac{\ln t}{t-3}y = \dfrac{2t}{t-3}\). \(p\) is continuous for \(t \gt 0,\ t \neq 3\); \(g\) for \(t \neq 3\). The open interval of continuity containing \(t_0 = 1\) is \(0 \lt t \lt 3\).

(b) \(y \equiv 0\) is a solution. So is \(y = \left(\tfrac{2t}{3}\right)^{3/2}\) for \(t \ge 0\): \(y' = \tfrac32\left(\tfrac{2t}{3}\right)^{1/2}\cdot\tfrac23 = \left(\tfrac{2t}{3}\right)^{1/2} = y^{1/3}\). \(\checkmark\) Here \(f = y^{1/3}\) is continuous, but \(\partial f/\partial y = \tfrac13 y^{-2/3}\) is undefined at \(y = 0\), so uniqueness is not guaranteed and indeed fails.

2.5 Autonomous equations and stability

Definitions

An equation \(y' = f(y)\), with no explicit \(t\), is autonomous. Its equilibria (critical points) are the roots \(y^*\) of \(f(y^*) = 0\); each gives a constant solution \(y(t) \equiv y^*\).

An equilibrium is asymptotically stable if nearby solutions approach it, unstable if some nearby solutions move away, and semistable if it attracts from one side and repels from the other.

Phase line. Draw the \(y\)-axis, mark the equilibria, and in each interval between them put an arrow up where \(f \gt 0\) and down where \(f \lt 0\). Because solutions can't cross equilibria (uniqueness), every solution either stays at an equilibrium or moves monotonically toward the next one in the direction of the arrow (or to \(\pm\infty\)).

Linear stability test

If \(f\) is differentiable at an equilibrium \(y^*\): \(f'(y^*) \lt 0 \Rightarrow\) asymptotically stable; \(f'(y^*) \gt 0 \Rightarrow\) unstable; \(f'(y^*) = 0 \Rightarrow\) test is inconclusive (use the phase line).

Reason: near \(y^*\), \(f(y) \approx f'(y^*)(y - y^*)\), so the deviation \(\eta = y - y^*\) obeys \(\eta' \approx f'(y^*)\eta\), which decays exactly when \(f'(y^*) \lt 0\).

Logistic equation

\[ y' = r y\left(1 - \frac{y}{K}\right), \qquad y(t) = \frac{K y_0}{y_0 + (K - y_0)e^{-rt}} \]

Equilibria \(0\) (unstable) and \(K\) (stable, the carrying capacity). Solutions starting in \(0 \lt y_0 \lt K/2\) have an inflection point at \(y = K/2\), where growth is fastest.

Example 2.9

Draw the phase line for \(y' = y^2 - 4y + 3\) and describe the long-time behaviour for \(y(0) = 0,\ 2,\ 4\).

Show solution

\(f(y) = (y-1)(y-3)\). Equilibria: \(y = 1,\ 3\). Signs: \(f \gt 0\) for \(y \lt 1\), \(f \lt 0\) for \(1 \lt y \lt 3\), \(f \gt 0\) for \(y \gt 3\).

Phase line: arrows point up below 1, down between 1 and 3, up above 3. So \(y=1\) is asymptotically stable and \(y = 3\) is unstable. Confirm with \(f'(y) = 2y - 4\): \(f'(1) = -2 \lt 0\), \(f'(3) = 2 \gt 0\).

\(y(0) = 0\): increases to 1. \(y(0) = 2\): decreases to 1. \(y(0) = 4\): increases without bound (in fact it blows up in finite time, since \(f\) grows like \(y^2\)).

Example 2.10 (semistable)

Classify the equilibrium of \(y' = (y - 2)^2\).

Show solution

Only equilibrium: \(y = 2\), with \(f'(2) = 0\), so the derivative test is silent. But \(f \ge 0\) everywhere: arrows point up on both sides. Solutions below 2 rise toward it; solutions above 2 rise away from it. So \(y = 2\) is semistable.

2.6 Exact equations and integrating factors

Idea: if the solution curves are level sets \(\psi(x,y) = C\) of some function, then differentiating along a curve gives \(\psi_x + \psi_y\,y' = 0\). So an equation of the form \(M + N y' = 0\) is easy whenever \(M = \psi_x\) and \(N = \psi_y\) for some \(\psi\). This is the same question as "is the vector field \((M, N)\) conservative?" from vector calculus.

Theorem (test for exactness)

Let \(M, N, M_y, N_x\) be continuous on a rectangle (or any simply connected region) \(R\). Then \(M(x,y)\,dx + N(x,y)\,dy = 0\) is exact in \(R\), i.e. there is \(\psi\) with \(\psi_x = M,\ \psi_y = N\), if and only if

\[ M_y = N_x \quad\text{throughout } R. \]

The solutions are then given implicitly by \(\psi(x,y) = C\).

Finding \(\psi\). Integrate \(M\) with respect to \(x\), adding an unknown \(h(y)\): \(\psi = \int M\,dx + h(y)\). Then differentiate in \(y\), set equal to \(N\), and solve for \(h'(y)\). (If \(h'\) depends on \(x\), you made an error or the equation isn't exact.)

Integrating factors. If the equation is not exact, look for \(\mu\) such that \(\mu M\,dx + \mu N\,dy = 0\) is. The condition \((\mu M)_y = (\mu N)_x\) is a PDE for \(\mu\), but if \(\mu\) depends only on \(x\) it becomes \(\mu M_y = \mu' N + \mu N_x\), i.e.

Key formula

\[ \frac{\mu'(x)}{\mu(x)} = \frac{M_y - N_x}{N} \;\;(\text{must depend on } x \text{ only}), \qquad \frac{\mu'(y)}{\mu(y)} = \frac{N_x - M_y}{M} \;\;(\text{must depend on } y \text{ only}). \]

Example 2.11

Solve \((2xy + 3)\,dx + (x^2 + 4y)\,dy = 0\).

Show solution

\(M_y = 2x\), \(N_x = 2x\): exact.

\(\psi = \int(2xy + 3)\,dx = x^2 y + 3x + h(y)\). Then \(\psi_y = x^2 + h'(y) = x^2 + 4y\), so \(h' = 4y\), \(h = 2y^2\).

\[ x^2 y + 3x + 2y^2 = C. \]

Example 2.12 (integrating factor)

Solve \((3xy + y^2)\,dx + (x^2 + xy)\,dy = 0\).

Show solution

\(M_y = 3x + 2y\), \(N_x = 2x + y\). Not exact.

\(\dfrac{M_y - N_x}{N} = \dfrac{x + y}{x(x + y)} = \dfrac1x\), a function of \(x\) only. So \(\mu = e^{\int dx/x} = x\).

New equation: \((3x^2 y + xy^2)\,dx + (x^3 + x^2 y)\,dy = 0\). Check: \(M_y = 3x^2 + 2xy = N_x\). \(\checkmark\)

\(\psi = \int (3x^2y + xy^2)\,dx = x^3 y + \tfrac12 x^2y^2 + h(y)\); \(\psi_y = x^3 + x^2 y + h' = x^3 + x^2 y\), so \(h = 0\).

\[ x^3 y + \tfrac12 x^2 y^2 = C. \]

2.7 Euler's method

When no formula works, follow the direction field numerically. From \((t_n, y_n)\), step forward along the tangent line for a time \(h\):

Euler's method

\[ t_{n+1} = t_n + h, \qquad y_{n+1} = y_n + h\,f(t_n, y_n) \]

Each step makes a local error of order \(h^2\) (the neglected Taylor term \(\tfrac12 y''h^2\)). Over a fixed interval you take about \(1/h\) steps, so the global error is order \(h\): halving \(h\) roughly halves the error. Better methods (improved Euler, Runge–Kutta) reach global order \(h^2\) and \(h^4\).

Example 2.13

Use Euler's method with \(h = 0.1\) to approximate \(y(0.3)\) for \(y' = t + y\), \(y(0) = 1\). Compare with the exact solution \(y = 2e^t - t - 1\).

Show solution \[ \begin{aligned} y_1 &= 1 + 0.1(0 + 1) = 1.1 \\ y_2 &= 1.1 + 0.1(0.1 + 1.1) = 1.22 \\ y_3 &= 1.22 + 0.1(0.2 + 1.22) = 1.362 \end{aligned} \]

Exact: \(y(0.3) = 2e^{0.3} - 1.3 \approx 1.3997\). Error \(\approx 0.038\). (Check the exact solution: \(y' = 2e^t - 1 = t + (2e^t - t - 1)\). \(\checkmark\)) Euler underestimates here because the solution is concave up, so tangent lines lie below it.

2.8 Substitutions: Bernoulli and homogeneous equations

Bernoulli equation

\(y' + p(t)y = q(t)y^n\), \(n \neq 0, 1\). Substituting \(v = y^{1-n}\) gives \(v' = (1-n)y^{-n}y'\), and the equation becomes linear in \(v\):

\[ v' + (1-n)p(t)\,v = (1-n)q(t). \]

Homogeneous (scale-invariant) equation

\(\dfrac{dy}{dx} = F\!\left(\dfrac{y}{x}\right)\). Substituting \(v = y/x\), so \(y = vx\) and \(y' = v + x v'\), gives the separable equation \(x\,v' = F(v) - v\).

(This use of "homogeneous" is unrelated to "homogeneous linear equation", an unfortunate clash of names.)

Example 2.14

(a) Solve the Bernoulli equation \(y' + y = y^2\). (b) Solve \(\dfrac{dy}{dx} = \dfrac{x^2 + y^2}{xy}\), \(x \gt 0\).

Show solution

(a) \(n = 2\), \(v = y^{-1}\). Then \(v' + (1-2)(1)v = (1-2)(1)\), i.e. \(v' - v = -1\). Integrating factor \(e^{-t}\): \((e^{-t}v)' = -e^{-t}\), so \(e^{-t}v = e^{-t} + C\), \(v = 1 + Ce^t\), and

\[ y = \frac{1}{1 + Ce^{t}} \quad(\text{plus the lost solution } y \equiv 0). \]

(b) Divide top and bottom by \(x^2\): \(F(v) = \dfrac{1 + v^2}{v} = \dfrac1v + v\). Then \(xv' = \dfrac1v\), so \(v\,dv = dx/x\), \(\tfrac12 v^2 = \ln x + C\). With \(v = y/x\):

\[ y^2 = 2x^2(\ln x + C). \]

Check (b): \(2yy' = 4x(\ln x + C) + 2x\), so \(y' = \dfrac{x(2\ln x + 2C + 1)}{y}\); and \(\dfrac{x^2 + y^2}{xy} = \dfrac{x^2(1 + 2\ln x + 2C)}{xy}\), the same. \(\checkmark\)

3. Second-order linear equations

Boyce & DiPrima Ch. 3 · Zill Ch. 4–5

Second-order equations are where Newton's law lives: force sets acceleration, which is the second derivative of position. The damped, driven spring and the series RLC circuit are the same equation, \(a y'' + b y' + c y = g(t)\), and understanding it completely (oscillation, decay, damping regimes, resonance) is one of the main payoffs of the course. The strategy has two halves. First solve the homogeneous equation (\(g = 0\)), whose solutions form a two-dimensional vector space; with constant coefficients, the guess \(e^{rt}\) reduces this to a quadratic. Then find any one particular solution of the full equation and add.

Theorem (structure of solutions)

Consider \(y'' + p(t)y' + q(t)y = g(t)\) with \(p, q, g\) continuous on an open interval \(I\) containing \(t_0\).

  1. Existence and uniqueness: for any \(y_0, y_0'\) there is exactly one solution with \(y(t_0) = y_0\), \(y'(t_0) = y_0'\), and it exists on all of \(I\).
  2. Superposition: if \(y_1, y_2\) solve the homogeneous equation, so does \(c_1y_1 + c_2y_2\).
  3. General solution: if \(y_1, y_2\) form a fundamental set (section 3.2) and \(Y\) is any particular solution of the nonhomogeneous equation, every solution is \(y = c_1y_1 + c_2y_2 + Y\).

3.1 Homogeneous equations with constant coefficients

Why \(e^{rt}\) works. For \(ay'' + by' + cy = 0\) we need a function whose derivatives are all proportional to the function itself, so that the three terms can cancel. The exponential is exactly that: \(\frac{d}{dt}e^{rt} = re^{rt}\). Substituting \(y = e^{rt}\) gives \((ar^2 + br + c)e^{rt} = 0\), and since \(e^{rt}\) never vanishes:

Characteristic equation

\[ ay'' + by' + cy = 0 \quad\longrightarrow\quad ar^2 + br + c = 0, \qquad r = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

The three cases

\[ \begin{array}{lll} b^2 - 4ac \gt 0 & r_1 \neq r_2 \text{ real} & y = c_1 e^{r_1 t} + c_2 e^{r_2 t} \\ b^2 - 4ac \lt 0 & r = \lambda \pm i\mu & y = e^{\lambda t}\left(c_1\cos\mu t + c_2\sin\mu t\right) \\ b^2 - 4ac = 0 & r_1 = r_2 = r & y = (c_1 + c_2 t)\,e^{rt} \end{array} \]

Complex roots. With \(r = \lambda + i\mu\), Euler's formula \(e^{i\theta} = \cos\theta + i\sin\theta\) gives

\[ e^{(\lambda + i\mu)t} = e^{\lambda t}\cos\mu t + i\,e^{\lambda t}\sin\mu t. \]

Because the equation has real coefficients, the real and imaginary parts of a complex solution are each real solutions. That gives \(e^{\lambda t}\cos\mu t\) and \(e^{\lambda t}\sin\mu t\). (The conjugate root \(\lambda - i\mu\) gives nothing new.) Physically: \(\lambda\) is the decay rate of the envelope and \(\mu\) is the angular frequency of oscillation.

Repeated root. If \(b^2 = 4ac\), then \(r = -b/(2a)\) and only one exponential is available. Try \(y = v(t)e^{rt}\): substituting gives \(a\,v''e^{rt} + (2ar + b)v'e^{rt} + (ar^2 + br + c)ve^{rt} = 0\). Both brackets vanish (the second because \(r\) is a root, the first because \(r = -b/2a\)), leaving \(v'' = 0\), so \(v = c_1 + c_2 t\). This is reduction of order (section 3.3) applied to this case.

Example 3.1 (real roots)

Solve \(y'' + y' - 6y = 0\), \(y(0) = 1\), \(y'(0) = 0\).

Show solution

\(r^2 + r - 6 = (r - 2)(r + 3) = 0\): \(r = 2, -3\). So \(y = c_1e^{2t} + c_2e^{-3t}\).

\[ \begin{aligned} y(0) &= c_1 + c_2 = 1 \\ y'(0) &= 2c_1 - 3c_2 = 0 \end{aligned} \]

From the second, \(c_1 = \tfrac32 c_2\); then \(\tfrac52 c_2 = 1\), \(c_2 = \tfrac25\), \(c_1 = \tfrac35\).

\[ y = \tfrac35 e^{2t} + \tfrac25 e^{-3t}. \]

Check: \(y'(0) = \tfrac65 - \tfrac65 = 0\). \(\checkmark\)

Example 3.2 (complex roots)

Solve \(y'' + 4y' + 13y = 0\), \(y(0) = 2\), \(y'(0) = -1\).

Show solution

\(r = \dfrac{-4 \pm\sqrt{16 - 52}}{2} = -2 \pm 3i\). So \(y = e^{-2t}(c_1\cos 3t + c_2\sin 3t)\).

\(y(0) = c_1 = 2\). Differentiate: \(y' = e^{-2t}\left[(-2c_1 + 3c_2)\cos 3t + (-2c_2 - 3c_1)\sin 3t\right]\), so \(y'(0) = -2c_1 + 3c_2 = -1\), giving \(c_2 = 1\).

\[ y = e^{-2t}(2\cos 3t + \sin 3t). \]

Example 3.3 (repeated root)

Solve \(y'' - 6y' + 9y = 0\), \(y(0) = 1\), \(y'(0) = 5\).

Show solution

\(r^2 - 6r + 9 = (r-3)^2\): \(r = 3\) (double). \(y = (c_1 + c_2t)e^{3t}\).

\(y(0) = c_1 = 1\). \(y' = c_2e^{3t} + 3(c_1 + c_2t)e^{3t}\), so \(y'(0) = c_2 + 3 = 5\), \(c_2 = 2\).

\[ y = (1 + 2t)e^{3t}. \]

3.2 The Wronskian and fundamental sets

The general solution needs two solutions that are "genuinely different" so that any pair of initial conditions can be matched. Matching \(y(t_0) = y_0,\ y'(t_0) = y_0'\) with \(c_1y_1 + c_2y_2\) is a \(2\times2\) linear system whose determinant is the Wronskian.

Definition

\[ W[y_1, y_2](t) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1 y_2' - y_1' y_2. \]

Two solutions \(y_1, y_2\) of the homogeneous equation form a fundamental set if \(W \neq 0\). Then \(c_1y_1 + c_2y_2\) is the general solution.

Theorem (Abel)

If \(y_1, y_2\) solve \(y'' + p(t)y' + q(t)y = 0\) on \(I\), then

\[ W(t) = C\exp\!\left(-\int p(t)\,dt\right). \]

Consequently \(W\) is either identically zero on \(I\) or never zero on \(I\). Proof sketch: differentiate \(W = y_1y_2' - y_1'y_2\) and use the equation to replace \(y''\): \(W' = y_1y_2'' - y_1''y_2 = -p\,W\).

Study tip

For two functions, \(W \neq 0\) is equivalent to "neither is a constant multiple of the other" when they are solutions of the same linear ODE. For constant-coefficient equations, the three cases above always give fundamental sets; you rarely need to compute \(W\) except for variation of parameters.

Example 3.4

Compute \(W[e^{2t}, e^{-3t}]\) and confirm Abel's formula for \(y'' + y' - 6y = 0\).

Show solution

\(W = e^{2t}(-3e^{-3t}) - (2e^{2t})e^{-3t} = -5e^{-t}\). Never zero, so a fundamental set.

Abel: \(p = 1\), so \(W = Ce^{-t}\). With \(C = -5\) they agree. \(\checkmark\)

3.3 Reduction of order

If one solution \(y_1\) of \(y'' + py' + qy = 0\) is known, set \(y = v(t)y_1(t)\). Substituting, the terms without derivatives of \(v\) vanish (because \(y_1\) is a solution), leaving a first-order linear equation for \(w = v'\):

\[ y_1 w' + (2y_1' + p\,y_1)\,w = 0. \]

Key formula

\[ y_2(t) = y_1(t)\int \frac{e^{-\int p(t)\,dt}}{y_1(t)^2}\,dt \]

Example 3.5

Given that \(y_1 = t^2\) solves \(t^2y'' - 3ty' + 4y = 0\) for \(t \gt 0\), find a second solution.

Show solution

Standard form: \(y'' - \frac3t y' + \frac4{t^2}y = 0\), so \(p = -3/t\) and \(e^{-\int p} = e^{3\ln t} = t^3\).

\[ y_2 = t^2\int\frac{t^3}{t^4}\,dt = t^2\int\frac{dt}{t} = t^2\ln t. \]

Check: \(y_2' = 2t\ln t + t\), \(y_2'' = 2\ln t + 3\). Then \(t^2(2\ln t + 3) - 3t(2t\ln t + t) + 4t^2\ln t = (2 - 6 + 4)t^2\ln t + (3 - 3)t^2 = 0\). \(\checkmark\)

3.4 Nonhomogeneous equations: undetermined coefficients

For constant coefficients and a forcing \(g(t)\) built from polynomials, exponentials, sines and cosines, the derivatives of \(g\) stay in a finite family of functions. So guess a particular solution \(Y\) that is a general combination of that family and solve for the coefficients.

Forcing \(g(t)\)Trial \(Y(t)\)
\(P_n(t)\) (degree \(n\) polynomial)\(t^s\,(A_nt^n + \cdots + A_1t + A_0)\)
\(P_n(t)\,e^{\alpha t}\)\(t^s\,(A_nt^n + \cdots + A_0)\,e^{\alpha t}\)
\(P_n(t)\,e^{\alpha t}\cos\beta t\) or \(\sin\beta t\)\(t^s e^{\alpha t}\left[(A_nt^n + \cdots + A_0)\cos\beta t + (B_nt^n + \cdots + B_0)\sin\beta t\right]\)

Here \(s \in \{0, 1, 2\}\) is the number of times \(\alpha + i\beta\) is a root of the characteristic equation (\(\alpha = \beta = 0\) for a pure polynomial). Equivalently: multiply by \(t\) until no term of \(Y\) solves the homogeneous equation. For a sum of forcings, handle each term separately and add (superposition).

Common mistake

Two classics. (1) For \(g = \sin\beta t\), you must include both \(\cos\beta t\) and \(\sin\beta t\) in \(Y\), since differentiation mixes them. (2) Forgetting the \(t^s\) factor. If the trial duplicates a homogeneous solution, substituting gives \(0 = g\), which is impossible. This is the method's way of telling you that you're at resonance.

Example 3.6

Find the general solution of \(y'' - 3y' - 4y = 3e^{2t}\).

Show solution

Homogeneous: \(r^2 - 3r - 4 = (r-4)(r+1)\), \(y_h = c_1e^{4t} + c_2e^{-t}\). Since 2 is not a root, \(s = 0\): try \(Y = Ae^{2t}\).

\(Y'' - 3Y' - 4Y = (4 - 6 - 4)Ae^{2t} = -6Ae^{2t} = 3e^{2t}\), so \(A = -\tfrac12\).

\[ y = c_1e^{4t} + c_2e^{-t} - \tfrac12 e^{2t}. \]

Example 3.7 (modification rule)

Find particular solutions of (a) \(y'' + y' = 2t\) and (b) \(y'' + 4y = 8\sin 2t\).

Show solution

(a) Characteristic roots: \(r(r + 1) = 0\), so \(r = 0, -1\). The forcing is a degree-1 polynomial, i.e. \(\alpha = 0\), which is a simple root: \(s = 1\). Try \(Y = t(At + B) = At^2 + Bt\).

\(Y' = 2At + B\), \(Y'' = 2A\). Then \(2A + 2At + B = 2t\): matching \(t\): \(2A = 2\), \(A = 1\); constants: \(2A + B = 0\), \(B = -2\). So \(Y = t^2 - 2t\). Check: \(2 + (2t - 2) = 2t\). \(\checkmark\)

(b) Roots \(\pm 2i\); forcing has \(\alpha + i\beta = 2i\), a simple root: \(s = 1\). Try \(Y = t\,u(t)\) with \(u = A\cos 2t + B\sin 2t\). Since \(u'' = -4u\):

\[ Y'' = 2u' + tu'' = 2u' - 4tu \quad\Rightarrow\quad Y'' + 4Y = 2u' = -4A\sin 2t + 4B\cos 2t. \]

Set equal to \(8\sin 2t\): \(A = -2\), \(B = 0\). So \(Y = -2t\cos 2t\), an oscillation whose amplitude grows linearly: resonance.

3.5 Variation of parameters

Undetermined coefficients needs constant coefficients and special forcing. Variation of parameters works for any \(g\) and any \(p, q\), as long as you know a fundamental set \(y_1, y_2\).

Derivation. For \(y'' + p y' + q y = g\), look for \(Y = u_1(t)y_1 + u_2(t)y_2\). There are two unknown functions and only one equation, so we can impose one extra condition. Choose

\[ u_1'y_1 + u_2'y_2 = 0, \]

which makes \(Y' = u_1y_1' + u_2y_2'\) (no \(u'\) terms). Then \(Y'' = u_1y_1'' + u_2y_2'' + u_1'y_1' + u_2'y_2'\). Substituting into the ODE, the terms \(u_1(y_1'' + py_1' + qy_1)\) and \(u_2(\cdots)\) vanish, leaving \(u_1'y_1' + u_2'y_2' = g\). Solve the \(2\times 2\) system by Cramer's rule:

\[ \begin{bmatrix} y_1 & y_2 \\ y_1' & y_2' \end{bmatrix}\begin{bmatrix} u_1' \\ u_2' \end{bmatrix} = \begin{bmatrix} 0 \\ g \end{bmatrix} \quad\Longrightarrow\quad u_1' = -\frac{y_2\,g}{W}, \quad u_2' = \frac{y_1\,g}{W}. \]

Variation of parameters

\[ Y(t) = -y_1(t)\int\frac{y_2(t)\,g(t)}{W(t)}\,dt + y_2(t)\int\frac{y_1(t)\,g(t)}{W(t)}\,dt \]

(valid for the equation in standard form, leading coefficient 1)

Common mistake

Using \(g\) from the un-normalised equation. For \(t^2y'' + \cdots = f(t)\), the formula needs \(g = f/t^2\).

Example 3.8

Find a particular solution of \(y'' - 2y' + y = \dfrac{e^t}{t}\), \(t \gt 0\).

Show solution

Undetermined coefficients can't handle \(1/t\). Homogeneous: \((r - 1)^2\), so \(y_1 = e^t\), \(y_2 = te^t\), and \(W = e^t(e^t + te^t) - e^t\cdot te^t = e^{2t}\).

\[ u_1' = -\frac{te^t\cdot e^t/t}{e^{2t}} = -1 \;\Rightarrow\; u_1 = -t, \qquad u_2' = \frac{e^t\cdot e^t/t}{e^{2t}} = \frac1t \;\Rightarrow\; u_2 = \ln t. \]

\(Y = -te^t + te^t\ln t\). The term \(-te^t\) is a homogeneous solution, so drop it: \(Y = te^t\ln t\).

Check: write \(Y = w e^t\) with \(w = t\ln t\). For this operator, \((we^t)'' - 2(we^t)' + we^t = w''e^t\). Since \(w' = \ln t + 1\), \(w'' = 1/t\), we get \(e^t/t\). \(\checkmark\)

3.6 Mechanical and electrical vibrations (free)

The two models

Spring–mass–damper (displacement \(u\) from equilibrium, mass \(m\), damping \(\gamma\), spring constant \(k\), external force \(F\)):

\[ m u'' + \gamma u' + k u = F(t) \]

Series RLC circuit (charge \(q\) on the capacitor, current \(i = q'\), source \(E\)):

\[ L q'' + R q' + \frac1C q = E(t) \]

Dictionary: \(m \leftrightarrow L\), \(\gamma \leftrightarrow R\), \(k \leftrightarrow 1/C\), \(F \leftrightarrow E\). Inductance is inertia, resistance is friction, and elastance \(1/C\) is stiffness.

Undamped (\(\gamma = 0\)): \(u = c_1\cos\omega_0t + c_2\sin\omega_0t\) with natural frequency \(\omega_0 = \sqrt{k/m}\) (or \(1/\sqrt{LC}\)). Writing it as one cosine is often clearer:

Amplitude–phase form

\[ c_1\cos\omega_0t + c_2\sin\omega_0t = A\cos(\omega_0t - \delta), \qquad A = \sqrt{c_1^2 + c_2^2},\quad \cos\delta = \frac{c_1}{A},\ \sin\delta = \frac{c_2}{A}. \]

Common mistake

Writing \(\delta = \arctan(c_2/c_1)\) without checking the quadrant. If \(c_1 \lt 0\), add \(\pi\). Use the signs of \(\cos\delta\) and \(\sin\delta\).

Damped: roots \(r = \dfrac{-\gamma \pm\sqrt{\gamma^2 - 4km}}{2m}\). Both roots have negative real part whenever \(\gamma \gt 0\), so all free motion decays. The discriminant sets the character:

Study tip

Physicists and control engineers write \(u'' + 2\zeta\omega_0 u' + \omega_0^2 u = 0\) with damping ratio \(\zeta = \dfrac{\gamma}{2\sqrt{km}}\) (for RLC, \(\zeta = \frac{R}{2}\sqrt{C/L}\)). Then \(\zeta \lt 1\), \(=1\), \(\gt 1\) are the three regimes, and the quasi-frequency is \(\omega_d = \omega_0\sqrt{1 - \zeta^2}\). The quality factor is \(Q = 1/(2\zeta)\).

Example 3.9 (underdamped spring)

A 2 kg mass hangs on a spring with \(k = 50\) N/m and damping \(\gamma = 8\) N·s/m. It is pulled down 0.1 m and released from rest. Find \(u(t)\), the quasi-period, and the critical damping coefficient.

Show solution

\(2u'' + 8u' + 50u = 0 \Rightarrow u'' + 4u' + 25u = 0\). Roots: \(r = -2 \pm\sqrt{4 - 25} = -2 \pm i\sqrt{21}\). Underdamped.

\(u = e^{-2t}(c_1\cos\sqrt{21}\,t + c_2\sin\sqrt{21}\,t)\). \(u(0) = c_1 = 0.1\). \(u'(0) = -2c_1 + \sqrt{21}\,c_2 = 0 \Rightarrow c_2 = \dfrac{0.2}{\sqrt{21}} \approx 0.0436\).

\[ u(t) = e^{-2t}\left(0.1\cos\sqrt{21}\,t + \frac{0.2}{\sqrt{21}}\sin\sqrt{21}\,t\right) \]

Quasi-frequency \(\mu = \sqrt{21} \approx 4.58\) rad/s, so quasi-period \(2\pi/\sqrt{21} \approx 1.37\) s, slightly longer than the undamped period \(2\pi/5 \approx 1.26\) s: damping slows the oscillation. Critical damping: \(\gamma_c = 2\sqrt{km} = 2\sqrt{100} = 20\) N·s/m, so \(\zeta = 8/20 = 0.4\).

Example 3.10 (RLC regimes)

A series RLC circuit has \(L = 0.5\) H and \(C = 2\) mF. (a) With \(R = 10\ \Omega\), find the roots and classify. (b) What resistance gives critical damping?

Show solution

Divide by \(L\): \(q'' + \frac{R}{L}q' + \frac{1}{LC}q = 0\). Here \(\frac{1}{LC} = \frac{1}{0.5 \times 0.002} = 1000\).

(a) \(R/L = 20\): \(r^2 + 20r + 1000 = 0\), \(r = -10 \pm\sqrt{100 - 1000} = -10 \pm 30i\). Underdamped: rings at 30 rad/s with envelope \(e^{-10t}\).

(b) \(R_c = 2\sqrt{L/C} = 2\sqrt{250} \approx 31.6\ \Omega\).

3.7 Forced vibrations, resonance and beats

Now drive the system: \(mu'' + \gamma u' + ku = F_0\cos\omega t\). The solution is (decaying transient) + (steady-state response at the driving frequency).

Steady state via complex exponentials. Replace \(\cos\omega t\) by \(e^{i\omega t}\) and try \(U e^{i\omega t}\): \((k - m\omega^2 + i\gamma\omega)U = F_0\). This is exactly phasor analysis: \(k - m\omega^2 + i\gamma\omega\) plays the role of an impedance. Taking the real part:

Steady-state response

\[ u_{ss}(t) = A\cos(\omega t - \delta), \qquad A = \frac{F_0}{\sqrt{(k - m\omega^2)^2 + \gamma^2\omega^2}}, \qquad \tan\delta = \frac{\gamma\omega}{k - m\omega^2},\ \ 0 \le \delta \le \pi. \]

The amplitude peaks where \((k - m\omega^2)^2 + \gamma^2\omega^2\) is smallest. Differentiating with respect to \(\omega^2\) gives

\[ \omega_{\max}^2 = \omega_0^2 - \frac{\gamma^2}{2m^2}, \qquad A_{\max} = \frac{F_0}{\gamma\omega_0\sqrt{1 - \gamma^2/(4mk)}}, \]

which exists only if \(\gamma^2 \lt 2mk\). For light damping, \(\omega_{\max} \approx \omega_0\) and \(A_{\max} \approx F_0/(\gamma\omega_0)\): the response grows like \(1/\gamma\). Compared with the static deflection \(F_0/k\), the gain is \(m\omega_0/\gamma = Q\). The phase lag \(\delta\) rises from 0 (well below resonance) through \(\pi/2\) (at \(\omega_0\)) to \(\pi\) (well above).

Undamped forcing (\(\gamma = 0\))

\(\omega \neq \omega_0\): \(u = c_1\cos\omega_0t + c_2\sin\omega_0t + \dfrac{F_0}{m(\omega_0^2 - \omega^2)}\cos\omega t\). Starting from rest at equilibrium,

\[ u = \frac{F_0}{m(\omega_0^2 - \omega^2)}\left(\cos\omega t - \cos\omega_0 t\right) = \left[\frac{2F_0}{m(\omega_0^2 - \omega^2)}\sin\frac{(\omega_0 - \omega)t}{2}\right]\sin\frac{(\omega_0 + \omega)t}{2}. \]

When \(\omega \approx \omega_0\), a fast oscillation at the average frequency is modulated by a slow envelope: beats.

\(\omega = \omega_0\) (resonance): particular solution \(\dfrac{F_0}{2m\omega_0}\,t\sin\omega_0 t\), unbounded linear growth.

Example 3.11 (steady state)

Find the steady-state solution of \(u'' + 2u' + 5u = 10\cos t\) and write it in amplitude–phase form.

Show solution

Try \(Y = A\cos t + B\sin t\), so \(Y'' = -Y\):

\[ (-A + 2B + 5A)\cos t + (-B - 2A + 5B)\sin t = (4A + 2B)\cos t + (4B - 2A)\sin t. \]

Match: \(4A + 2B = 10\), \(4B - 2A = 0\). So \(A = 2B\), \(10B = 10\), \(B = 1\), \(A = 2\). \(Y = 2\cos t + \sin t\).

Example 3.12 (beats and resonance)

Starting from \(u(0) = 0\), \(u'(0) = 0\), solve (a) \(u'' + 16u = 7\cos 3t\) and (b) \(u'' + 16u = 8\cos 4t\).

Show solution

4. Higher-order linear equations

Boyce & DiPrima Ch. 4 · Zill Ch. 4

Everything from Chapter 3 generalises with almost no new ideas: an \(n\)th-order linear equation has an \(n\)-dimensional space of homogeneous solutions, the characteristic equation becomes a degree-\(n\) polynomial, and repeated roots get extra powers of \(t\). The main practical difficulty is just factoring the polynomial. Fourth-order equations show up in beam bending (Euler–Bernoulli), and higher-order equations in general arise when you eliminate variables from a coupled system, e.g. two coupled masses or a multi-stage filter.

4.1 General theory

Theorem

If \(p_1, \ldots, p_n, g\) are continuous on an open interval \(I\) containing \(t_0\), then

\[ y^{(n)} + p_1(t)y^{(n-1)} + \cdots + p_{n-1}(t)y' + p_n(t)y = g(t) \]

with \(n\) initial conditions \(y(t_0), y'(t_0), \ldots, y^{(n-1)}(t_0)\) has a unique solution on all of \(I\). Solutions \(y_1, \ldots, y_n\) of the homogeneous equation form a fundamental set iff their Wronskian

\[ W = \det\begin{bmatrix} y_1 & y_2 & \cdots & y_n \\ y_1' & y_2' & \cdots & y_n' \\ \vdots & & & \vdots \\ y_1^{(n-1)} & y_2^{(n-1)} & \cdots & y_n^{(n-1)} \end{bmatrix} \]

is nonzero at some (hence every) point of \(I\). Abel's formula generalises to \(W = C\exp\left(-\int p_1\,dt\right)\).

4.2 Constant coefficients

Root-to-solution rules

For \(a_ny^{(n)} + \cdots + a_0y = 0\), factor \(Z(r) = a_nr^n + \cdots + a_0\).

\[ \begin{array}{ll} \text{real root } r \text{ of multiplicity } k: & e^{rt},\ te^{rt},\ \ldots,\ t^{k-1}e^{rt} \\ \text{complex pair } \lambda \pm i\mu \text{ of multiplicity } k: & t^je^{\lambda t}\cos\mu t,\ \ t^je^{\lambda t}\sin\mu t,\quad j = 0, \ldots, k-1 \end{array} \]

The total count is always \(n\).

Study tip

Factoring tools: the rational root theorem (try \(\pm\)divisors of \(a_0\) over divisors of \(a_n\)) plus synthetic division; grouping; treating \(r^2\) as a variable for even polynomials. For \(r^n = a\), write \(a\) in polar form and take the \(n\) roots spaced \(2\pi/n\) apart.

Example 4.1

Find general solutions of (a) \(y''' - y'' - y' + y = 0\); (b) \(y^{(4)} + 8y'' + 16y = 0\); (c) \(y^{(4)} - 16y = 0\).

Show solution

(a) Group: \(r^3 - r^2 - r + 1 = r^2(r - 1) - (r - 1) = (r - 1)(r^2 - 1) = (r-1)^2(r+1)\).

\[ y = (c_1 + c_2t)e^{t} + c_3e^{-t}. \]

(b) \(r^4 + 8r^2 + 16 = (r^2 + 4)^2\): roots \(\pm 2i\), each double.

\[ y = (c_1 + c_2t)\cos 2t + (c_3 + c_4t)\sin 2t. \]

(c) \(r^4 - 16 = (r^2 - 4)(r^2 + 4)\): roots \(\pm 2,\ \pm 2i\).

\[ y = c_1e^{2t} + c_2e^{-2t} + c_3\cos 2t + c_4\sin 2t. \]

4.3 Nonhomogeneous equations

Undetermined coefficients works exactly as before, with \(s\) now possibly larger than 2 (it is the multiplicity of the forcing's exponent as a root of \(Z\)). Variation of parameters also generalises: \(Y = \sum u_k y_k\) with \(u_k' = g\,W_k/W\), where \(W_k\) is \(W\) with its \(k\)th column replaced by \((0, \ldots, 0, 1)^T\). In practice, for \(n \ge 3\) this is heavy, and Laplace transforms (Chapter 6) are usually faster.

Example 4.2

Find a particular solution of \(y''' - y' = 2 + 3e^{t}\).

Show solution

\(Z(r) = r^3 - r = r(r-1)(r+1)\). Both \(0\) and \(1\) are simple roots, so each forcing term needs \(s = 1\).

For \(2\): \(Y_1 = At\). \(Y_1''' - Y_1' = -A = 2\), so \(A = -2\).

For \(3e^t\): \(Y_2 = Bte^t\). The \(k\)th derivative of \(te^t\) is \((t + k)e^t\), so \(Y_2''' - Y_2' = B[(t+3) - (t+1)]e^t = 2Be^t = 3e^t\), \(B = \tfrac32\).

\[ Y = -2t + \tfrac32 te^{t}. \]

A simply supported beam of length \(L\) with uniform load \(w\) satisfies \(EI\,y^{(4)} = w\), \(y(0) = y''(0) = y(L) = y''(L) = 0\) (no deflection and no bending moment at the supports). Find \(y(x)\).

\[ y(x) = \frac{w}{24EI}\left(x^4 - 2Lx^3 + L^3x\right), \qquad y_{\max} = y(L/2) = \frac{5wL^4}{384EI}. \]

5. Series solutions

Boyce & DiPrima Ch. 5 · Zill Ch. 6

Constant-coefficient equations are the exception. The equations of mathematical physics, from separating variables in cylindrical or spherical coordinates, have variable coefficients, and their solutions are usually new functions (Bessel, Legendre, Hermite, Airy) that are defined by power series. The method: assume \(y = \sum a_nx^n\), substitute, and turn the ODE into a recurrence for the coefficients. Where the coefficients become singular, the plain power series can fail, and the Frobenius method allows a non-integer leading power \(x^r\).

5.1 Series solutions near an ordinary point

Definitions

For \(P(x)y'' + Q(x)y' + R(x)y = 0\) with polynomial (or analytic) coefficients, \(x_0\) is an ordinary point if \(p = Q/P\) and \(q = R/P\) are analytic at \(x_0\) (for polynomials with no common factors: \(P(x_0) \neq 0\)). Otherwise it is a singular point.

Theorem

If \(x_0\) is an ordinary point, the general solution is \(y = \sum_{n=0}^\infty a_n(x - x_0)^n = a_0y_1(x) + a_1y_2(x)\), where \(y_1, y_2\) are power series forming a fundamental set. Their radius of convergence is at least the minimum of the radii of convergence of \(p\) and \(q\); for rational coefficients, at least the distance from \(x_0\) to the nearest zero of \(P\) in the complex plane.

Study tip (the mechanics)

  1. Write \(y = \sum a_nx^n\), \(y' = \sum na_nx^{n-1}\), \(y'' = \sum n(n-1)a_nx^{n-2}\).
  2. Multiply in the coefficients, then shift indices so every sum shows \(x^n\).
  3. Peel off any low-order terms so all sums start at the same \(n\).
  4. Set the coefficient of each power to zero: that's the recurrence.
  5. Generate terms; look for a pattern; separate the \(a_0\) and \(a_1\) families.

Example 5.1

Find series solutions of \(y'' - xy' - y = 0\) about \(x_0 = 0\), and identify one in closed form.

Show solution

Substituting:

\[ \sum_{n=2}^\infty n(n-1)a_nx^{n-2} - \sum_{n=1}^\infty na_nx^n - \sum_{n=0}^\infty a_nx^n = 0. \]

Shift the first sum (\(n \to n + 2\)): \(\sum_{n=0}^\infty (n+2)(n+1)a_{n+2}x^n\). The middle sum can start at \(n = 0\) since its \(n=0\) term is zero. Collecting \(x^n\):

\[ (n+2)(n+1)a_{n+2} - (n + 1)a_n = 0 \quad\Longrightarrow\quad a_{n+2} = \frac{a_n}{n + 2}. \]

Even terms: \(a_2 = \frac{a_0}{2},\ a_4 = \frac{a_0}{2\cdot4},\ a_6 = \frac{a_0}{2\cdot4\cdot6}\), so \(a_{2k} = \dfrac{a_0}{2^kk!}\):

\[ y_1 = \sum_{k=0}^\infty\frac{x^{2k}}{2^kk!} = \sum_{k=0}^\infty \frac{(x^2/2)^k}{k!} = e^{x^2/2}. \]

Odd terms: \(a_3 = \frac{a_1}{3},\ a_5 = \frac{a_1}{3\cdot5},\ a_7 = \frac{a_1}{3\cdot5\cdot7}\):

\[ y_2 = x + \frac{x^3}{3} + \frac{x^5}{15} + \frac{x^7}{105} + \cdots \]

Check \(y_1\): \(y_1' = xy_1\), \(y_1'' = y_1 + x^2y_1\), so \(y_1'' - xy_1' - y_1 = y_1 + x^2y_1 - x^2y_1 - y_1 = 0\). \(\checkmark\) Since \(P = 1\) never vanishes, both series converge for all \(x\).

Example 5.2 (radius of convergence without solving)

Give a lower bound for the radius of convergence of series solutions of \((x^2 + 4)y'' + xy' + y = 0\) about \(x_0 = 1\).

Show solution

\(P(x) = x^2 + 4\) vanishes at \(x = \pm 2i\). Nothing goes wrong on the real line, but the distance in \(\mathbb{C}\) from \(1\) to \(2i\) is \(\sqrt{1 + 4} = \sqrt5\). So \(\rho \ge \sqrt5\).

5.2 Euler equations

The simplest equation with a singular point is the Euler (equidimensional) equation

\[ x^2y'' + \alpha xy' + \beta y = 0. \]

Each term scales the same way under \(x \to cx\), so the natural guess is a power \(y = x^r\) (for \(x \gt 0\)). Then \(x^2y'' = r(r-1)x^r\), \(xy' = rx^r\):

Indicial equation and solutions (\(x \gt 0\))

\[ F(r) = r(r - 1) + \alpha r + \beta = 0 \] \[ \begin{array}{ll} r_1 \neq r_2 \text{ real}: & y = c_1x^{r_1} + c_2x^{r_2} \\ r_1 = r_2 = r: & y = (c_1 + c_2\ln x)\,x^{r} \\ r = \lambda \pm i\mu: & y = x^\lambda\left[c_1\cos(\mu\ln x) + c_2\sin(\mu\ln x)\right] \end{array} \]

For \(x \lt 0\), replace \(x\) by \(|x|\).

Why logs: the substitution \(x = e^z\) turns an Euler equation into a constant-coefficient equation in \(z\), so \(e^{rz} = x^r\), \(ze^{rz} = x^r\ln x\) and \(e^{\lambda z}\cos\mu z = x^\lambda\cos(\mu\ln x)\).

Example 5.3

Solve for \(x \gt 0\): (a) \(x^2y'' + 3xy' + 5y = 0\); (b) \(x^2y'' - xy' + y = 0\).

Show solution

(a) \(r(r-1) + 3r + 5 = r^2 + 2r + 5 = 0\), \(r = -1 \pm 2i\).

\[ y = x^{-1}\left[c_1\cos(2\ln x) + c_2\sin(2\ln x)\right]. \]

(b) \(r(r - 1) - r + 1 = r^2 - 2r + 1 = (r-1)^2\), \(r = 1\) double.

\[ y = c_1x + c_2x\ln x. \]

5.3 Regular singular points and the Frobenius method

Definition

A singular point \(x_0\) of \(y'' + p(x)y' + q(x)y = 0\) is regular if \((x - x_0)p(x)\) and \((x - x_0)^2q(x)\) are both analytic at \(x_0\). Otherwise it is irregular. Interpretation: the singularity is "no worse than Euler's".

Theorem (Frobenius), stated at \(x_0 = 0\)

Let \(x = 0\) be a regular singular point with \(xp(x) = \sum p_nx^n\), \(x^2q(x) = \sum q_nx^n\) converging for \(|x| \lt \rho\). Let \(r_1 \ge r_2\) be the real roots of the indicial equation

\[ F(r) = r(r - 1) + p_0r + q_0 = 0. \]

Then there is a solution \(y_1 = |x|^{r_1}\sum_{n=0}^\infty a_nx^n\) (\(a_0 = 1\)) for \(0 \lt |x| \lt \rho\). A second solution has the form:

  • \(r_1 - r_2\) not an integer: \(y_2 = |x|^{r_2}\sum b_nx^n\);
  • \(r_1 = r_2\): \(y_2 = y_1\ln|x| + |x|^{r_1}\sum_{n\ge1} b_nx^n\);
  • \(r_1 - r_2 = N\), a positive integer: \(y_2 = a\,y_1\ln|x| + |x|^{r_2}\sum c_nx^n\), where the constant \(a\) may be zero.

Common mistake

Reading \(p_0\) and \(q_0\) from the wrong normalisation. Divide by the coefficient of \(y''\) first, then form \(xp\) and \(x^2q\) and evaluate at 0. A quick alternative: multiply the equation so it reads \(x^2y'' + x[\ldots]y' + [\ldots]y = 0\); the brackets evaluated at \(x = 0\) are \(p_0\) and \(q_0\).

Example 5.4 (Frobenius, roots not differing by an integer)

Find two Frobenius solutions of \(2xy'' + y' - y = 0\) about \(x = 0\).

Show solution

Multiply by \(x/2\): \(x^2y'' + x\cdot\tfrac12\,y' - \tfrac{x}{2}y = 0\). So \(p_0 = \tfrac12\), \(q_0 = 0\): regular singular point. Indicial: \(r(r - 1) + \tfrac12r = r\left(r - \tfrac12\right) = 0\), so \(r_1 = \tfrac12\), \(r_2 = 0\). The difference \(\tfrac12\) is not an integer, so two series solutions exist.

Substitute \(y = \sum a_nx^{n+r}\):

\[ 2xy'' + y' = \sum_{n=0}^\infty (n + r)\left[2(n + r - 1) + 1\right]a_nx^{n+r-1} = \sum_{n=0}^\infty (n+r)(2n + 2r - 1)a_nx^{n+r-1}, \] \[ y = \sum_{n=0}^\infty a_nx^{n+r} = \sum_{n=1}^\infty a_{n-1}x^{n+r-1}. \]

The \(n = 0\) coefficient gives \(r(2r - 1)a_0 = 0\), the indicial equation again. For \(n \ge 1\):

\[ a_n = \frac{a_{n-1}}{(n + r)(2n + 2r - 1)}. \]

\(r = \tfrac12\): \(a_n = \dfrac{a_{n-1}}{n(2n + 1)}\), so \(a_1 = \tfrac13,\ a_2 = \tfrac1{30},\ a_3 = \tfrac{1}{630}\) (with \(a_0 = 1\)):

\[ y_1 = x^{1/2}\left(1 + \frac{x}{3} + \frac{x^2}{30} + \frac{x^3}{630} + \cdots\right). \]

\(r = 0\): \(a_n = \dfrac{a_{n-1}}{n(2n - 1)}\), so \(a_1 = 1,\ a_2 = \tfrac16,\ a_3 = \tfrac1{90}\):

\[ y_2 = 1 + x + \frac{x^2}{6} + \frac{x^3}{90} + \cdots \]

Bonus: these are \(y_2 = \cosh\sqrt{2x}\) and \(y_1 = \tfrac{1}{\sqrt2}\sinh\sqrt{2x}\). Expanding \(\cosh s = \sum s^{2k}/(2k)!\) with \(s^2 = 2x\) gives \(1 + x + \tfrac{4x^2}{24} + \tfrac{8x^3}{720} = 1 + x + \tfrac{x^2}{6} + \tfrac{x^3}{90}\). \(\checkmark\)

5.4 Bessel and Legendre equations

Bessel's equation of order \(\nu \ge 0\)

\[ x^2y'' + xy' + (x^2 - \nu^2)y = 0 \]

Regular singular point at \(x = 0\), indicial equation \(r^2 - \nu^2 = 0\), \(r = \pm\nu\). The Frobenius solution with \(r = \nu\) is the Bessel function of the first kind

\[ J_\nu(x) = \sum_{k=0}^\infty \frac{(-1)^k}{k!\,\Gamma(k + \nu + 1)}\left(\frac{x}{2}\right)^{2k+\nu}. \]

The second solution \(Y_\nu\) (Bessel function of the second kind) is singular at \(x = 0\). Bessel functions arise whenever you separate variables in cylindrical coordinates: drumhead modes, heat flow in a cylinder, cylindrical waveguides and optical fibres, and the sideband amplitudes of FM signals (\(J_n(\beta)\)).

Legendre's equation

\[ (1 - x^2)y'' - 2xy' + \alpha(\alpha + 1)y = 0 \]

\(x = 0\) is an ordinary point and the recurrence is \(a_{n+2} = -\dfrac{(\alpha - n)(\alpha + n + 1)}{(n+2)(n+1)}a_n\). When \(\alpha = n\) is a non-negative integer, one series terminates, giving the Legendre polynomials \(P_0 = 1,\ P_1 = x,\ P_2 = \tfrac12(3x^2 - 1),\ P_3 = \tfrac12(5x^3 - 3x)\). They are orthogonal on \([-1, 1]\) and describe the angular dependence of solutions in spherical coordinates: multipole expansions in electrostatics and the angular parts of hydrogen-atom wavefunctions.

Example 5.5 (deriving \(J_0\))

Find the Frobenius solution of Bessel's equation of order zero, \(x^2y'' + xy' + x^2y = 0\).

Show solution

\(p_0 = 1\), \(q_0 = 0\): \(r^2 = 0\), a double root \(r = 0\), so the first solution is an ordinary power series \(y = \sum a_nx^n\).

\(x^2y'' + xy' = \sum [n(n-1) + n]a_nx^n = \sum n^2a_nx^n\), and \(x^2y = \sum_{n\ge2} a_{n-2}x^n\). Matching powers:

\(x^1\): \(1^2a_1 = 0\), so \(a_1 = 0\) and all odd coefficients vanish. \(x^n,\ n \ge 2\): \(n^2a_n + a_{n-2} = 0\), so \(a_n = -a_{n-2}/n^2\).

\[ a_2 = -\frac{a_0}{4}, \quad a_4 = \frac{a_0}{4\cdot16} = \frac{a_0}{64}, \quad a_6 = -\frac{a_0}{64\cdot36} = -\frac{a_0}{2304}, \quad a_{2k} = \frac{(-1)^ka_0}{2^{2k}(k!)^2}. \]

With \(a_0 = 1\):

\[ J_0(x) = \sum_{k=0}^\infty\frac{(-1)^k}{(k!)^2}\left(\frac{x}{2}\right)^{2k} = 1 - \frac{x^2}{4} + \frac{x^4}{64} - \frac{x^6}{2304} + \cdots \]

Because \(r\) is a double root, the second solution contains \(J_0(x)\ln x\) and blows up at the origin, which is why physical problems including the axis \(r = 0\) keep only \(J_0\).

6. Laplace transforms

Boyce & DiPrima Ch. 6 · Zill Ch. 7

The Laplace transform turns calculus into algebra: differentiation in \(t\) becomes multiplication by \(s\), so a linear constant-coefficient IVP becomes an algebraic equation for \(Y(s)\), with the initial conditions built in automatically. Its real strength shows with discontinuous and impulsive inputs (switches, pulses, hammer blows) where undetermined coefficients is clumsy. For an EE, this is the same \(s\)-domain you use for circuits and control: the transfer function, poles and zeros, and the impulse response all come from this chapter.

6.1 Definition and basic properties

Definition

\[ \mathcal{L}\{f(t)\} = F(s) = \int_0^\infty e^{-st}f(t)\,dt, \]

defined for those \(s\) where the improper integral converges.

Theorem (existence)

If \(f\) is piecewise continuous on \([0, A]\) for every \(A \gt 0\) and is of exponential order, i.e. \(|f(t)| \le Ke^{at}\) for all \(t \ge M\), then \(F(s)\) exists for all \(s \gt a\). (Example: \(e^{t^2}\) is not of exponential order and has no Laplace transform.)

Transform of a derivative. Integrate by parts with \(u = e^{-st}\), \(dv = f'(t)\,dt\):

\[ \int_0^\infty e^{-st}f'(t)\,dt = \Big[e^{-st}f(t)\Big]_0^\infty + s\int_0^\infty e^{-st}f(t)\,dt = -f(0) + sF(s), \]

since \(e^{-st}f(t) \to 0\) for \(s\) large enough (exponential order). Applying this twice gives the second-derivative rule.

Core properties

\[ \begin{aligned} \mathcal{L}\{af + bg\} &= aF + bG \\ \mathcal{L}\{f'\} &= sF(s) - f(0) \\ \mathcal{L}\{f''\} &= s^2F(s) - sf(0) - f'(0) \\ \mathcal{L}\{e^{ct}f(t)\} &= F(s - c) \\ \mathcal{L}\{t^nf(t)\} &= (-1)^nF^{(n)}(s) \end{aligned} \]

Example 6.1 (transforms from the definition)

Compute \(\mathcal{L}\{e^{at}\}\), then use it to get \(\mathcal{L}\{\cos bt\}\) and \(\mathcal{L}\{\sin bt\}\).

Show solution \[ \mathcal{L}\{e^{at}\} = \int_0^\infty e^{-(s-a)t}\,dt = \left[\frac{-e^{-(s-a)t}}{s - a}\right]_0^\infty = \frac{1}{s - a}, \qquad s \gt a. \]

The same computation works for complex \(a = ib\) (with \(s \gt 0\)):

\[ \mathcal{L}\{e^{ibt}\} = \frac{1}{s - ib} = \frac{s + ib}{s^2 + b^2}. \]

Since \(e^{ibt} = \cos bt + i\sin bt\) and \(\mathcal{L}\) is linear, matching real and imaginary parts:

\[ \mathcal{L}\{\cos bt\} = \frac{s}{s^2 + b^2}, \qquad \mathcal{L}\{\sin bt\} = \frac{b}{s^2 + b^2}. \]

Study tip: inverting with partial fractions

  • Distinct linear factors: use the cover-up rule. For \(\frac{N(s)}{(s - a)(s - b)}\), the coefficient of \(\frac1{s-a}\) is \(N(a)/(a - b)\).
  • Repeated factor \((s - a)^k\): include \(\frac{A_1}{s-a} + \cdots + \frac{A_k}{(s-a)^k}\); invert with \(\mathcal{L}^{-1}\{(s-a)^{-k}\} = \frac{t^{k-1}e^{at}}{(k-1)!}\).
  • Irreducible quadratic: complete the square to \((s - \lambda)^2 + \mu^2\), split the numerator as \(A(s - \lambda) + B\mu\), and invert to \(e^{\lambda t}(A\cos\mu t + B\sin\mu t)\).

6.2 Solving initial value problems

Recipe: (1) transform both sides, using the derivative rules to insert the initial conditions; (2) solve algebraically for \(Y(s)\); (3) partial fractions; (4) invert with the table.

For \(ay'' + by' + cy = g(t)\) this always gives

\[ Y(s) = \underbrace{\frac{G(s)}{as^2 + bs + c}}_{\text{forced (zero-state) response}} + \underbrace{\frac{(as + b)y(0) + ay'(0)}{as^2 + bs + c}}_{\text{free (zero-input) response}}. \]

The denominator is the characteristic polynomial with \(r\) renamed \(s\). Its roots, the poles, are the characteristic roots from Chapter 3.

Example 6.2

Solve \(y'' - 2y' - 3y = 0\), \(y(0) = 1\), \(y'(0) = 7\).

Show solution \[ \left[s^2Y - s - 7\right] - 2\left[sY - 1\right] - 3Y = 0 \;\Longrightarrow\; (s^2 - 2s - 3)Y = s + 5. \] \[ Y = \frac{s + 5}{(s - 3)(s + 1)} = \frac{A}{s - 3} + \frac{B}{s + 1}, \quad A = \frac{3 + 5}{3 + 1} = 2,\quad B = \frac{-1 + 5}{-1 - 3} = -1. \] \[ y = 2e^{3t} - e^{-t}. \]

Check: \(y(0) = 1\), \(y'(0) = 6 + 1 = 7\). \(\checkmark\)

Example 6.3

Solve \(y'' + y = 2e^{-t}\), \(y(0) = 0\), \(y'(0) = 0\).

Show solution

\((s^2 + 1)Y = \dfrac{2}{s + 1}\), so \(Y = \dfrac{2}{(s+1)(s^2+1)} = \dfrac{A}{s+1} + \dfrac{Bs + C}{s^2+1}\).

Cover-up at \(s = -1\): \(A = 2/2 = 1\). Then \(2 = (s^2 + 1) + (Bs + C)(s + 1)\). Comparing \(s^2\): \(0 = 1 + B\), so \(B = -1\). Constants: \(2 = 1 + C\), so \(C = 1\). (Check \(s^1\): \(B + C = 0\). \(\checkmark\))

\[ y = e^{-t} - \cos t + \sin t. \]

Check: \(y'' = e^{-t} + \cos t - \sin t\), so \(y'' + y = 2e^{-t}\); \(y(0) = 0\); \(y'(0) = -1 + 0 + 1 = 0\). \(\checkmark\)

6.3 Step functions and discontinuous forcing

Definition

The unit step (Heaviside function) is \(u_c(t) = 0\) for \(t \lt c\) and \(1\) for \(t \ge c\). A switch that is on during \([a, b)\) is \(u_a(t) - u_b(t)\). A function that changes formula at \(t = c\), from \(f_1\) to \(f_2\), is \(f_1(t) + u_c(t)\left[f_2(t) - f_1(t)\right]\).

Theorem (time shift)

\[ \mathcal{L}\{u_c(t)\,f(t - c)\} = e^{-cs}F(s), \qquad \mathcal{L}^{-1}\{e^{-cs}F(s)\} = u_c(t)\,f(t - c). \]

Proof: \(\int_c^\infty e^{-st}f(t - c)\,dt\); substitute \(\tau = t - c\) to get \(e^{-cs}\int_0^\infty e^{-s\tau}f(\tau)\,d\tau\).

Common mistake

\(\mathcal{L}\{u_c(t)f(t)\}\) is not \(e^{-cs}F(s)\). The function multiplying \(u_c\) must be written in terms of \(t - c\) first. Equivalently, \(\mathcal{L}\{u_c(t)f(t)\} = e^{-cs}\mathcal{L}\{f(t + c)\}\).

Example 6.4

Find \(\mathcal{L}\{u_2(t)\,t^2\}\).

Show solution

Rewrite in powers of \(t - 2\): \(t^2 = (t - 2)^2 + 4(t - 2) + 4\). (Or use \(f(t + 2) = (t+2)^2 = t^2 + 4t + 4\).) Then

\[ \mathcal{L}\{u_2(t)t^2\} = e^{-2s}\left(\frac{2}{s^3} + \frac{4}{s^2} + \frac{4}{s}\right). \]

Example 6.5 (RC circuit with a pulse)

An RC circuit with \(RC = 1\) s, initially uncharged, is driven by a 5 V pulse lasting 2 s: \(v' + v = 5\left[u_0(t) - u_2(t)\right]\), \(v(0) = 0\). Find \(v(t)\).

Show solution

\((s + 1)V = 5\,\dfrac{1 - e^{-2s}}{s}\), so \(V = 5(1 - e^{-2s})\,H(s)\) with \(H(s) = \dfrac{1}{s(s+1)} = \dfrac1s - \dfrac1{s+1}\), whose inverse is \(h(t) = 1 - e^{-t}\).

\[ v(t) = 5\left(1 - e^{-t}\right) - 5u_2(t)\left(1 - e^{-(t-2)}\right). \]

Piecewise: for \(0 \le t \lt 2\), \(v = 5(1 - e^{-t})\) (charging toward 5 V). For \(t \ge 2\), \(v = 5e^{-(t-2)} - 5e^{-t} = 5(e^2 - 1)e^{-t}\), an exponential discharge starting from \(v(2) = 5(1 - e^{-2}) \approx 4.32\) V. The solution is continuous; its derivative jumps at \(t = 2\), as it must when the input jumps.

Example 6.6

Solve \(y'' + 4y = u_\pi(t)\), \(y(0) = 0\), \(y'(0) = 0\).

Show solution

\(Y = \dfrac{e^{-\pi s}}{s(s^2 + 4)}\). Partial fractions: \(\dfrac{1}{s(s^2+4)} = \dfrac14\left(\dfrac1s - \dfrac{s}{s^2 + 4}\right)\), whose inverse is \(\tfrac14(1 - \cos 2t)\).

\[ y = \tfrac14u_\pi(t)\left[1 - \cos 2(t - \pi)\right] = \tfrac14u_\pi(t)\left(1 - \cos 2t\right). \]

(Here \(\cos 2(t - \pi) = \cos 2t\) because \(2\pi\) is a period.) Nothing happens until the force switches on; then the mass oscillates about the new equilibrium \(\tfrac14\).

6.4 Impulse functions and the Dirac delta

A large force acting for a very short time (a hammer blow, a lightning strike, a voltage spike) is characterised by its total impulse \(\int F\,dt\). Idealise it as a pulse of height \(1/\varepsilon\) on \([c, c + \varepsilon)\) and let \(\varepsilon \to 0\).

Definition (Dirac delta)

\(\delta(t - c)\) is the limit of those unit-area pulses. It is not a function but is defined by its action:

\[ \int_{-\infty}^{\infty}\delta(t - c)f(t)\,dt = f(c) \quad (f \text{ continuous}), \qquad \mathcal{L}\{\delta(t - c)\} = e^{-cs}\ (c \ge 0). \]

Formally \(\delta(t - c) = u_c'(t)\).

Effect on \(ay'' + by' + cy = \delta(t - t_0)\): \(y\) stays continuous but \(y'\) jumps by \(1/a\) at \(t_0\). (Integrate the equation across \(t_0\): only the \(ay''\) term can produce a finite contribution.) For a mass, an impulse \(I\) changes the momentum by \(I\).

Example 6.7

Solve \(y'' + 2y' + 5y = \delta(t - 1)\), \(y(0) = 0\), \(y'(0) = 0\).

Show solution

\((s^2 + 2s + 5)Y = e^{-s}\), so \(Y = e^{-s}\dfrac{1}{(s + 1)^2 + 4}\). Since \(\mathcal{L}^{-1}\left\{\dfrac{1}{(s+1)^2 + 4}\right\} = \tfrac12e^{-t}\sin 2t\),

\[ y = \tfrac12u_1(t)\,e^{-(t-1)}\sin 2(t - 1). \]

At rest until \(t = 1\), then kicked: \(y'(1^+) = \tfrac12\cdot 2 = 1\), a jump of \(1/a = 1\). \(\checkmark\) Afterwards it rings down with quasi-frequency 2.

6.5 Convolution and transfer functions

Definition

\[ (f * g)(t) = \int_0^t f(t - \tau)\,g(\tau)\,d\tau. \]

Convolution is commutative, associative and distributive, but \(f * 1 \neq f\) in general.

Convolution theorem

\[ \mathcal{L}\{f * g\} = F(s)\,G(s), \qquad \mathcal{L}^{-1}\{F(s)G(s)\} = (f * g)(t). \]

Transfer function and impulse response

For \(ay'' + by' + cy = g(t)\) with zero initial conditions, \(Y(s) = H(s)G(s)\) where

\[ H(s) = \frac{1}{as^2 + bs + c}, \qquad h(t) = \mathcal{L}^{-1}\{H(s)\}. \]

\(h\) is the impulse response (the response to \(\delta(t)\)), and the zero-state response to any input is

\[ y(t) = (h * g)(t) = \int_0^t h(t - \tau)\,g(\tau)\,d\tau. \]

The system is (asymptotically) stable iff every pole of \(H\) has negative real part. For a stable system, the steady-state response to \(\cos\omega t\) is \(|H(i\omega)|\cos(\omega t + \arg H(i\omega))\): the frequency response.

Study tip (EE connection)

For the RC low-pass filter \(RC\,v_{out}' + v_{out} = v_{in}\), \(H(s) = \dfrac{1}{RCs + 1}\): one pole at \(-1/RC\), impulse response \(\frac{1}{RC}e^{-t/RC}\), and \(|H(i\omega)| = 1/\sqrt{1 + (\omega RC)^2}\), the familiar \(-3\) dB point at \(\omega = 1/RC\). For the series RLC with output across the capacitor, \(H(s) = \dfrac{1}{LCs^2 + RCs + 1}\). The damping regimes of Chapter 3 are statements about where these poles sit.

Example 6.8

(a) Use convolution to find \(\mathcal{L}^{-1}\left\{\dfrac{1}{s^2(s^2 + 1)}\right\}\). (b) Express the solution of \(y'' + 4y = g(t)\), \(y(0) = y'(0) = 0\), for an arbitrary input \(g\).

Show solution

(a) \(\frac1{s^2} \leftrightarrow t\) and \(\frac1{s^2 + 1} \leftrightarrow \sin t\). So the inverse is

\[ \int_0^t (t - \tau)\sin\tau\,d\tau = t\left[-\cos\tau\right]_0^t - \left[\sin\tau - \tau\cos\tau\right]_0^t = t - t\cos t - \sin t + t\cos t = t - \sin t. \]

Check with partial fractions: \(\frac{1}{s^2(s^2+1)} = \frac1{s^2} - \frac1{s^2+1} \leftrightarrow t - \sin t\). \(\checkmark\)

(b) \(H(s) = \dfrac1{s^2 + 4}\), \(h(t) = \tfrac12\sin 2t\). So

\[ y(t) = \frac12\int_0^t \sin 2(t - \tau)\,g(\tau)\,d\tau. \]

This formula works for any integrable \(g\), even one with no closed-form transform.

7. Systems of first-order linear equations

Boyce & DiPrima Ch. 7 · Zill Ch. 8

Real systems have several interacting state variables: currents in coupled loops, positions of coupled masses, concentrations in connected tanks. Writing them as one vector equation \(\mathbf{x}' = A\mathbf{x}\) brings in linear algebra: the eigenvalues of \(A\) play the role of the characteristic roots, and the eigenvectors give the directions along which the system behaves like a simple exponential. In two dimensions, the eigenvalues completely determine the geometry of the trajectories (the phase portrait), which is the language of stability used in control and dynamics. This is also the state-space form \(\mathbf{x}' = A\mathbf{x} + B\mathbf{u}\) from control theory.

7.1 Matrix formulation

Definitions

A first-order linear system is \(\mathbf{x}' = P(t)\mathbf{x} + \mathbf{g}(t)\), with \(\mathbf{x}(t) \in \mathbb{R}^n\). Here we focus on constant \(P = A\).

Any \(n\)th-order equation is a system: for \(y'' + py' + qy = g\), set \(x_1 = y\), \(x_2 = y'\):

\[ \begin{bmatrix} x_1 \\ x_2 \end{bmatrix}' = \begin{bmatrix} 0 & 1 \\ -q & -p \end{bmatrix}\begin{bmatrix} x_1 \\ x_2 \end{bmatrix} + \begin{bmatrix} 0 \\ g \end{bmatrix}. \]

This is also how numerical solvers handle higher-order equations.

Theorem (structure)

If \(P(t)\) and \(\mathbf{g}(t)\) are continuous on \(I\), the IVP with \(\mathbf{x}(t_0) = \mathbf{x}_0\) has a unique solution on \(I\). The homogeneous system has \(n\) solutions \(\mathbf{x}^{(1)}, \ldots, \mathbf{x}^{(n)}\) whose Wronskian \(W = \det\left[\mathbf{x}^{(1)} \cdots \mathbf{x}^{(n)}\right]\) is nonzero, and every solution is \(\mathbf{x} = c_1\mathbf{x}^{(1)} + \cdots + c_n\mathbf{x}^{(n)}\).

Why eigenvectors. Try \(\mathbf{x} = \boldsymbol{\xi}e^{rt}\) with a constant vector \(\boldsymbol{\xi}\). Then \(r\boldsymbol{\xi}e^{rt} = A\boldsymbol{\xi}e^{rt}\), i.e.

Eigenvalue problem

\[ (A - rI)\boldsymbol{\xi} = \mathbf{0}, \qquad \det(A - rI) = 0. \]

For \(2\times2\): \(r^2 - (\operatorname{tr}A)\,r + \det A = 0\).

Example 7.1 (RLC circuit in state-space form)

Write the series RLC circuit with source \(v_{in}(t)\) as a first-order system in the state variables \(i\) (inductor current) and \(v_C\) (capacitor voltage).

Show solution

KVL: \(L\,i' + Ri + v_C = v_{in}\). Capacitor: \(C\,v_C' = i\). So

\[ \begin{bmatrix} i \\ v_C \end{bmatrix}' = \begin{bmatrix} -R/L & -1/L \\ 1/C & 0 \end{bmatrix}\begin{bmatrix} i \\ v_C \end{bmatrix} + \begin{bmatrix} 1/L \\ 0 \end{bmatrix}v_{in}. \]

\(\operatorname{tr}A = -R/L\), \(\det A = 1/(LC)\), so the eigenvalues solve \(r^2 + \frac{R}{L}r + \frac{1}{LC} = 0\), exactly the characteristic equation of \(Lq'' + Rq' + q/C = 0\). Same physics, two formulations.

7.2 Real distinct eigenvalues

If \(A\) (\(n\times n\)) has \(n\) real, distinct eigenvalues \(r_k\) with eigenvectors \(\boldsymbol{\xi}^{(k)}\), then \(\mathbf{x} = \sum c_k\boldsymbol{\xi}^{(k)}e^{r_kt}\). In 2D, trajectories along an eigenvector stay on that line, moving in (if \(r \lt 0\)) or out (if \(r \gt 0\)).

Example 7.2 (saddle)

Solve \(\mathbf{x}' = \begin{bmatrix} 1 & 1 \\ 4 & 1 \end{bmatrix}\mathbf{x}\), \(\mathbf{x}(0) = \begin{bmatrix} 2 \\ 0 \end{bmatrix}\), and describe the phase portrait.

Show solution

\(\det(A - rI) = (1 - r)^2 - 4 = 0 \Rightarrow 1 - r = \pm 2 \Rightarrow r = 3, -1\).

\(r = 3\): \(\begin{bmatrix} -2 & 1 \\ 4 & -2 \end{bmatrix}\boldsymbol{\xi} = \mathbf{0} \Rightarrow \xi_2 = 2\xi_1\), \(\boldsymbol{\xi}^{(1)} = \begin{bmatrix} 1 \\ 2 \end{bmatrix}\).

\(r = -1\): \(\begin{bmatrix} 2 & 1 \\ 4 & 2 \end{bmatrix}\boldsymbol{\xi} = \mathbf{0} \Rightarrow \xi_2 = -2\xi_1\), \(\boldsymbol{\xi}^{(2)} = \begin{bmatrix} 1 \\ -2 \end{bmatrix}\).

\[ \mathbf{x} = c_1\begin{bmatrix} 1 \\ 2 \end{bmatrix}e^{3t} + c_2\begin{bmatrix} 1 \\ -2 \end{bmatrix}e^{-t}. \]

Initial condition: \(c_1 + c_2 = 2\), \(2c_1 - 2c_2 = 0\), so \(c_1 = c_2 = 1\).

Phase portrait: eigenvalues of opposite sign make the origin a saddle (unstable). Trajectories come in along the line \(x_2 = -2x_1\) and leave along \(x_2 = 2x_1\). Every trajectory with \(c_1 \neq 0\) eventually runs off along the unstable direction.

7.3 Complex eigenvalues

For real \(A\), complex eigenvalues come in conjugate pairs \(r = \lambda \pm i\mu\) with conjugate eigenvectors \(\boldsymbol{\xi} = \mathbf{a} \pm i\mathbf{b}\). As in Chapter 3, take the real and imaginary parts of one complex solution:

Real solutions from a complex pair

\[ \mathbf{u}(t) = e^{\lambda t}\left(\mathbf{a}\cos\mu t - \mathbf{b}\sin\mu t\right), \qquad \mathbf{v}(t) = e^{\lambda t}\left(\mathbf{a}\sin\mu t + \mathbf{b}\cos\mu t\right). \]

Trajectories rotate with angular frequency \(\mu\) and grow (\(\lambda \gt 0\)), decay (\(\lambda \lt 0\)) or stay on closed ellipses (\(\lambda = 0\)). To find the direction of rotation, evaluate \(A\mathbf{x}\) at a convenient point such as \((1, 0)\).

Example 7.3 (spiral)

Find the general solution of \(\mathbf{x}' = \begin{bmatrix} -1 & -4 \\ 1 & -1 \end{bmatrix}\mathbf{x}\) and classify the origin.

Show solution

\((-1 - r)^2 + 4 = 0 \Rightarrow r = -1 \pm 2i\).

For \(r = -1 + 2i\): \(A - rI = \begin{bmatrix} -2i & -4 \\ 1 & -2i \end{bmatrix}\). The second row gives \(\xi_1 = 2i\,\xi_2\); take \(\boldsymbol{\xi} = \begin{bmatrix} 2i \\ 1 \end{bmatrix} = \begin{bmatrix} 0 \\ 1 \end{bmatrix} + i\begin{bmatrix} 2 \\ 0 \end{bmatrix}\), so \(\mathbf{a} = (0, 1)^T\), \(\mathbf{b} = (2, 0)^T\).

\[ \mathbf{x} = c_1e^{-t}\begin{bmatrix} -2\sin 2t \\ \cos 2t \end{bmatrix} + c_2e^{-t}\begin{bmatrix} 2\cos 2t \\ \sin 2t \end{bmatrix}. \]

Check the first: its derivative is \(e^{-t}(2\sin 2t - 4\cos 2t,\ -\cos 2t - 2\sin 2t)^T\), and \(A\) times it is \(e^{-t}(2\sin 2t - 4\cos 2t,\ -2\sin 2t - \cos 2t)^T\). \(\checkmark\)

\(\lambda = -1 \lt 0\): stable spiral. At \((1, 0)\), \(\mathbf{x}' = (-1, 1)\): moving up, so the rotation is counterclockwise.

7.4 Repeated eigenvalues

If \(r\) is a double eigenvalue with two independent eigenvectors (only possible in 2D if \(A = rI\)), the solutions are \(\boldsymbol{\xi}^{(1)}e^{rt}\), \(\boldsymbol{\xi}^{(2)}e^{rt}\). If there is only one eigenvector \(\boldsymbol{\xi}\) (the defective case), the second solution needs a generalised eigenvector \(\boldsymbol{\eta}\):

Defective double eigenvalue

\[ \mathbf{x}^{(2)} = \boldsymbol{\xi}\,te^{rt} + \boldsymbol{\eta}\,e^{rt}, \qquad\text{where}\quad (A - rI)\boldsymbol{\eta} = \boldsymbol{\xi}. \]

Common mistake

Guessing \(\boldsymbol{\xi}te^{rt}\) alone, by analogy with Chapter 3. It fails: substituting leaves an extra \(\boldsymbol{\xi}e^{rt}\) term that the \(\boldsymbol{\eta}e^{rt}\) piece is there to cancel.

Example 7.4

Solve \(\mathbf{x}' = \begin{bmatrix} 1 & -1 \\ 1 & 3 \end{bmatrix}\mathbf{x}\).

Show solution

\(\operatorname{tr}A = 4\), \(\det A = 3 + 1 = 4\): \(r^2 - 4r + 4 = (r - 2)^2\), \(r = 2\) double.

\(A - 2I = \begin{bmatrix} -1 & -1 \\ 1 & 1 \end{bmatrix}\): one eigenvector \(\boldsymbol{\xi} = (1, -1)^T\).

Generalised eigenvector: \(-\eta_1 - \eta_2 = 1\) (the second row is the same equation). Take \(\boldsymbol{\eta} = (0, -1)^T\).

\[ \mathbf{x} = c_1\begin{bmatrix} 1 \\ -1 \end{bmatrix}e^{2t} + c_2\left(\begin{bmatrix} 1 \\ -1 \end{bmatrix}te^{2t} + \begin{bmatrix} 0 \\ -1 \end{bmatrix}e^{2t}\right). \]

Check: \(\mathbf{x}^{(2)\prime} = \boldsymbol{\xi}e^{2t} + 2\boldsymbol{\xi}te^{2t} + 2\boldsymbol{\eta}e^{2t}\), while \(A\mathbf{x}^{(2)} = 2\boldsymbol{\xi}te^{2t} + (2\boldsymbol{\eta} + \boldsymbol{\xi})e^{2t}\). Equal. \(\checkmark\) The origin is an unstable improper (degenerate) node.

7.5 Phase portraits in the plane

For \(\mathbf{x}' = A\mathbf{x}\) in 2D with \(\det A \neq 0\), the origin is the only equilibrium and its type depends on \(\tau = \operatorname{tr}A\) and \(\Delta = \det A\) through \(r = \frac12\left(\tau \pm\sqrt{\tau^2 - 4\Delta}\right)\):

EigenvaluesTrace–determinant testTypeStability
Real, opposite signs\(\Delta \lt 0\)SaddleUnstable
Real, same sign, distinct\(\Delta \gt 0,\ \tau^2 \gt 4\Delta\)NodeStable if \(\tau \lt 0\), unstable if \(\tau \gt 0\)
Real, equal\(\tau^2 = 4\Delta\)Proper node (if \(A = rI\)) or improper nodeSign of \(\tau\)

Study tip

Sketch the \(\tau\)–\(\Delta\) plane once and memorise it: the parabola \(\Delta = \tau^2/4\) separates nodes (below) from spirals (above), the \(\Delta\)-axis (\(\tau = 0\), \(\Delta \gt 0\)) holds centers, and everything below \(\Delta = 0\) is a saddle. Asymptotic stability is exactly \(\tau \lt 0\) and \(\Delta \gt 0\), the 2D version of "all poles in the left half-plane". For a stable node, trajectories enter the origin tangent to the eigenvector of the eigenvalue closest to zero (the slow direction).

Example 7.5

Classify the origin for (a) \(\begin{bmatrix} -2 & 1 \\ 1 & -2 \end{bmatrix}\), (b) \(\begin{bmatrix} 0 & 1 \\ -4 & 0 \end{bmatrix}\), (c) \(\begin{bmatrix} 3 & -2 \\ 2 & -2 \end{bmatrix}\).

Show solution

(a) \(\tau = -4\), \(\Delta = 3\), \(\tau^2 - 4\Delta = 4 \gt 0\): eigenvalues \(-1, -3\), stable node. Eigenvectors \((1, 1)\) for \(-1\) (the slow direction) and \((1, -1)\) for \(-3\).

(b) \(\tau = 0\), \(\Delta = 4\): eigenvalues \(\pm 2i\), center. This is \(x_1'' + 4x_1 = 0\), an undamped oscillator; orbits are ellipses \(4x_1^2 + x_2^2 = \text{const}\).

(c) \(\Delta = -6 + 4 = -2 \lt 0\): saddle. Eigenvalues from \(r^2 - r - 2 = 0\): \(r = 2\) with \((2, 1)\), \(r = -1\) with \((1, 2)\).

7.6 Fundamental matrices and the matrix exponential

Definitions

A fundamental matrix \(\Psi(t)\) has a fundamental set of solutions as its columns. The general solution is \(\mathbf{x} = \Psi(t)\mathbf{c}\), and the IVP solution is \(\mathbf{x} = \Psi(t)\Psi(t_0)^{-1}\mathbf{x}_0\).

The matrix exponential is

\[ e^{At} = I + At + \frac{A^2t^2}{2!} + \frac{A^3t^3}{3!} + \cdots \]

It satisfies \(\frac{d}{dt}e^{At} = Ae^{At}\) and \(e^{A\cdot 0} = I\), so it is the special fundamental matrix \(\Phi(t) = \Psi(t)\Psi(0)^{-1}\), and \(\mathbf{x}(t) = e^{At}\mathbf{x}_0\), exactly like the scalar case.

Computing \(e^{At}\)

Diagonalisable \(A = TDT^{-1}\) (columns of \(T\) are eigenvectors):

\[ e^{At} = T\,e^{Dt}\,T^{-1}, \qquad e^{Dt} = \operatorname{diag}(e^{r_1t}, \ldots, e^{r_nt}). \]

If \(A = rI + N\) with \(N^2 = 0\): \(e^{At} = e^{rt}(I + Nt)\).

Common mistake

\(e^{A + B} = e^Ae^B\) only when \(AB = BA\). It works for \(rI + N\) because \(rI\) commutes with everything. Also, \(e^{At}\) is not the matrix of entrywise exponentials.

Example 7.6

Compute \(e^{At}\) for (a) \(A = \begin{bmatrix} 1 & 1 \\ 4 & 1 \end{bmatrix}\) (from Example 7.2) and (b) \(A = \begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix}\).

Show solution

(a) \(T = \begin{bmatrix} 1 & 1 \\ 2 & -2 \end{bmatrix}\), \(\det T = -4\), \(T^{-1} = \dfrac{1}{-4}\begin{bmatrix} -2 & -1 \\ -2 & 1 \end{bmatrix} = \begin{bmatrix} 1/2 & 1/4 \\ 1/2 & -1/4 \end{bmatrix}\).

\[ e^{At} = \begin{bmatrix} e^{3t} & e^{-t} \\ 2e^{3t} & -2e^{-t} \end{bmatrix}\begin{bmatrix} 1/2 & 1/4 \\ 1/2 & -1/4 \end{bmatrix} = \begin{bmatrix} \frac12(e^{3t} + e^{-t}) & \frac14(e^{3t} - e^{-t}) \\ e^{3t} - e^{-t} & \frac12(e^{3t} + e^{-t}) \end{bmatrix}. \]

Checks: at \(t = 0\) this is \(I\); its derivative at \(t = 0\) is \(\begin{bmatrix} 1 & 1 \\ 4 & 1 \end{bmatrix} = A\). \(\checkmark\)

(b) \(A^2 = -I\), so the series splits into even and odd parts: \(e^{At} = I\left(1 - \frac{t^2}{2!} + \cdots\right) + A\left(t - \frac{t^3}{3!} + \cdots\right) = I\cos t + A\sin t\):

\[ e^{At} = \begin{bmatrix} \cos t & \sin t \\ -\sin t & \cos t \end{bmatrix}, \]

a rotation (clockwise) by angle \(t\): the undamped oscillator.

7.7 Nonhomogeneous systems

Variation of parameters for systems

\[ \mathbf{x}(t) = e^{At}\mathbf{x}_0 + \int_0^t e^{A(t - s)}\,\mathbf{g}(s)\,ds \]

(free response + convolution of the "impulse response matrix" \(e^{At}\) with the input). For general \(P(t)\), \(\mathbf{x}_p = \Psi(t)\int\Psi^{-1}(t)\mathbf{g}(t)\,dt\).

Other methods: undetermined coefficients (guess vector coefficients; e.g. for constant \(\mathbf{g} = \mathbf{b}\) and invertible \(A\), the constant solution is \(\mathbf{x}_p = -A^{-1}\mathbf{b}\)), diagonalisation (decouple with \(\mathbf{x} = T\mathbf{y}\)), or Laplace transforms: \((sI - A)\mathbf{X} = \mathbf{x}_0 + \mathbf{G}(s)\), so the transfer matrix is \((sI - A)^{-1}\).

Example 7.7

Find the general solution of \(\mathbf{x}' = \begin{bmatrix} -2 & 1 \\ 1 & -2 \end{bmatrix}\mathbf{x} + \begin{bmatrix} 1 \\ 2 \end{bmatrix}\) and its long-time limit.

Show solution

Particular (constant) solution: \(\mathbf{x}_p = -A^{-1}\mathbf{b}\). With \(\det A = 3\), \(A^{-1} = \frac13\begin{bmatrix} -2 & -1 \\ -1 & -2 \end{bmatrix}\), so

\[ \mathbf{x}_p = \frac13\begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix}\begin{bmatrix} 1 \\ 2 \end{bmatrix} = \begin{bmatrix} 4/3 \\ 5/3 \end{bmatrix}. \]

Check: \(A\mathbf{x}_p = (-8/3 + 5/3,\ 4/3 - 10/3) = (-1, -2) = -\mathbf{b}\). \(\checkmark\)

\[ \mathbf{x} = c_1\begin{bmatrix} 1 \\ 1 \end{bmatrix}e^{-t} + c_2\begin{bmatrix} 1 \\ -1 \end{bmatrix}e^{-3t} + \begin{bmatrix} 4/3 \\ 5/3 \end{bmatrix}. \]

Both eigenvalues are negative, so every solution tends to \((4/3, 5/3)\): the system's DC operating point.

  3. Solve \(\mathbf{x}' = \begin{bmatrix} 1 & -5 \\ 1 & -3 \end{bmatrix}\mathbf{x}\) and classify.

    \(\tau = -2\), \(\Delta = 2\): \(r = -1 \pm i\). For \(r = -1 + i\), \(\boldsymbol{\xi} = (2 + i, 1)^T\). Real solutions: \(e^{-t}(2\cos t - \sin t,\ \cos t)^T\) and \(e^{-t}(\cos t + 2\sin t,\ \sin t)^T\). Stable spiral.

  5. For the RLC state matrix in Example 7.1, for which \(R\) is the origin a spiral? A node?

8. Nonlinear systems and stability

Boyce & DiPrima Ch. 9

Most real systems are nonlinear (pendulums, populations, transistors, lasers) and almost none have closed-form solutions. The key insight is that near an equilibrium, a smooth nonlinear system looks like its linearisation, so the phase portrait classification of Chapter 7 tells you the local picture. Stitching the local pictures together, with help from conserved quantities and nullclines, gives the global behaviour. This is the same small-signal analysis an EE does when biasing a transistor at an operating point.

8.1 Critical points and linearisation

Definitions

For the autonomous system \(x' = F(x, y)\), \(y' = G(x, y)\), a critical point \((x_0, y_0)\) satisfies \(F = G = 0\). It is stable if solutions starting close stay close for all \(t \gt 0\), asymptotically stable if in addition they converge to it, and unstable otherwise.

The Jacobian at the critical point is

\[ J = \begin{bmatrix} F_x & F_y \\ G_x & G_y \end{bmatrix}_{(x_0, y_0)}, \]

and the linearised system for the deviation \(\mathbf{u} = (x - x_0, y - y_0)\) is \(\mathbf{u}' = J\mathbf{u}\).

Theorem (when linearisation can be trusted)

Let \(F, G\) have continuous second partial derivatives near an isolated critical point, with \(\det J \neq 0\), and let \(r_1, r_2\) be the eigenvalues of \(J\).

  • If the eigenvalues are real and distinct, or complex with nonzero real part, the nonlinear system has the same type and stability (node, saddle or spiral) locally.
  • If \(r_1 = r_2\) (a node for the linearisation), the nonlinear system has a node or a spiral, with the same stability.
  • If \(r_{1,2} = \pm i\mu\) (a center for the linearisation), the nonlinear system may have a center or a spiral, and its stability is undetermined by linearisation.

Study tip

Workflow: (1) solve \(F = 0\), \(G = 0\) simultaneously (factor; sketching nullclines helps); (2) compute the general Jacobian once; (3) evaluate it at each critical point and use the trace–determinant table. For a linearised center, look for a conserved quantity \(E(x,y)\) (\(dE/dt = 0\) along solutions); closed level curves around the point mean a true center.

Common mistake

Missing critical points. In \(x(3 - x - 2y) = 0\) and \(y(2 - x - y) = 0\), each equation has two factors, so there are four combinations to check. Also, don't declare a nonlinear center stable or unstable from the linearisation alone.

8.2 The pendulum

A pendulum of length \(L\) with damping obeys \(\theta'' + \gamma\theta' + \omega^2\sin\theta = 0\), \(\omega^2 = g/L\). With \(x = \theta\), \(y = \theta'\):

\[ x' = y, \qquad y' = -\omega^2\sin x - \gamma y. \]

Example 8.1

Find and classify the critical points of the damped pendulum with \(\omega = 1\), \(\gamma = 0.5\). Then discuss the undamped case.

Show solution

Critical points: \(y = 0\) and \(\sin x = 0\), so \((n\pi, 0)\). Jacobian: \(J = \begin{bmatrix} 0 & 1 \\ -\cos x & -\gamma \end{bmatrix}\).

Hanging down, \((0, 0)\) (and \((2k\pi, 0)\)): \(J = \begin{bmatrix} 0 & 1 \\ -1 & -0.5 \end{bmatrix}\), \(\tau = -0.5\), \(\Delta = 1\), \(\tau^2 - 4\Delta = -3.75 \lt 0\): asymptotically stable spiral, which the theorem guarantees carries over to the nonlinear system.

Inverted, \((\pi, 0)\) (and odd multiples): \(\cos\pi = -1\), \(J = \begin{bmatrix} 0 & 1 \\ 1 & -0.5 \end{bmatrix}\), \(\Delta = -1 \lt 0\): saddle, unstable.

Undamped (\(\gamma = 0\)): at the origin \(J\) has eigenvalues \(\pm i\), a linear center, so the theorem is inconclusive. But the energy

\[ E(x, y) = \tfrac12y^2 + \omega^2(1 - \cos x) \]

satisfies \(\dfrac{dE}{dt} = yy' + \omega^2\sin x\,x' = y(-\omega^2\sin x) + \omega^2\sin x\,y = 0\). Near the origin its level curves are closed ovals, so the origin is a true center. With damping, \(dE/dt = -\gamma y^2 \le 0\): energy leaks away, which is why the spiral is inward. The level curve through the saddles, \(E = 2\omega^2\), is the separatrix dividing swinging motion from whirling over the top.

8.3 Population models: predator–prey and competition

Lotka–Volterra predator–prey

Prey \(x\), predators \(y\), all constants positive:

\[ x' = x(a - \alpha y), \qquad y' = y(-c + \gamma x). \]

Critical points \((0,0)\) (saddle) and \(\left(\frac{c}{\gamma}, \frac{a}{\alpha}\right)\), where \(J\) has eigenvalues \(\pm i\sqrt{ac}\) (linear center). The quantity \(V = \gamma x - c\ln x + \alpha y - a\ln y\) is conserved (separate \(dy/dx\) to see this), so orbits are closed: populations cycle forever with period \(\approx 2\pi/\sqrt{ac}\) for small oscillations.

Example 8.2 (predator–prey)

Analyse \(x' = x(1 - 0.5y)\), \(y' = y(-0.75 + 0.25x)\).

Show solution

Critical points: \((0, 0)\) and \(x = 0.75/0.25 = 3\), \(y = 1/0.5 = 2\): \((3, 2)\).

Jacobian: \(J = \begin{bmatrix} 1 - 0.5y & -0.5x \\ 0.25y & -0.75 + 0.25x \end{bmatrix}\).

At \((0, 0)\): \(\operatorname{diag}(1, -0.75)\), a saddle (prey grows along the \(x\)-axis; predators die out along the \(y\)-axis).

At \((3, 2)\): \(J = \begin{bmatrix} 0 & -1.5 \\ 0.5 & 0 \end{bmatrix}\), \(r^2 + 0.75 = 0\), \(r = \pm i\sqrt{0.75} \approx \pm 0.866i\). Linear center; the conserved \(V\) confirms closed orbits. Small cycles have period \(2\pi/0.866 \approx 7.3\) time units. At \((4, 2)\), \(x' = 0\) and \(y' = 2(0.25) \gt 0\), so the orbits run counterclockwise: prey peaks come a quarter-cycle before predator peaks.

Example 8.3 (competing species)

Analyse \(x' = x(3 - x - 2y)\), \(y' = y(2 - x - y)\) for \(x, y \ge 0\).

Show solution

Critical points (four combinations): \((0, 0)\); \(y = 0,\ x = 3\): \((3, 0)\); \(x = 0,\ y = 2\): \((0, 2)\); and \(x + 2y = 3,\ x + y = 2\): \((1, 1)\).

Jacobian: \(J = \begin{bmatrix} 3 - 2x - 2y & -2x \\ -y & 2 - x - 2y \end{bmatrix}\).

  • \((0,0)\): \(\operatorname{diag}(3, 2)\), unstable node.
  • \((3,0)\): \(\begin{bmatrix} -3 & -6 \\ 0 & -1 \end{bmatrix}\), eigenvalues \(-3, -1\): stable node.
  • \((0,2)\): \(\begin{bmatrix} -1 & 0 \\ -2 & -2 \end{bmatrix}\), eigenvalues \(-1, -2\): stable node.
  • \((1,1)\): \(\begin{bmatrix} -1 & -2 \\ -1 & -1 \end{bmatrix}\), \(\Delta = 1 - 2 = -1 \lt 0\): saddle.

Interpretation: competitive exclusion. Coexistence at \((1,1)\) is unstable; depending on which side of the saddle's stable separatrix the initial state lies, either \(x\) wins (\(\to (3,0)\)) or \(y\) wins (\(\to (0,2)\)).

Practice problems

  1. Find and classify the critical points of \(x' = x - y\), \(y' = x^2 - 4\).
    Answer

Origin: eigenvalues \(\pm i\); the conserved energy \(E = \frac12y^2 + \frac12x^2 - \frac14x^4\) has a local minimum there, so it is a true center. \((\pm1,0)\): \(J = \begin{bmatrix} 0 & 1 \\ 2 & 0 \end{bmatrix}\), saddles.

  3. For the damped pendulum with \(\omega = 1\), \(\gamma = 2.5\), classify the origin.

  5. Show that for \(x' = -y - x^3\), \(y' = x - y^3\), the linearisation at the origin is a center, but the origin is actually asymptotically stable.
    Answer

    \(J(0,0) = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}\), eigenvalues \(\pm i\). With \(V = x^2 + y^2\): \(V' = 2x(-y - x^3) + 2y(x - y^3) = -2(x^4 + y^4) \lt 0\) away from the origin, so distance to the origin strictly decreases: a stable spiral. (This is a Lyapunov-function argument.)

9. Fourier series and partial differential equations

Boyce & DiPrima Ch. 10 (Sturm–Liouville theory in Ch. 11)

The classic PDEs of physics (heat diffusion, wave propagation, electrostatic potential) are linear, so superposition applies. Separation of variables looks for building-block solutions that are products \(X(x)T(t)\). The boundary conditions turn the \(X\) equation into an eigenvalue problem whose solutions are sines and cosines; to match an arbitrary initial condition, you add up infinitely many of them. That requires expanding a function as a sum of sines and cosines, which is a Fourier series, the same decomposition into harmonics that underlies signal analysis and spectra.

9.1 Two-point boundary value problems and eigenvalue problems

Unlike IVPs, boundary value problems (conditions at two different points) can have no solution or infinitely many. Example: \(y'' + y = 0\) has general solution \(c_1\cos x + c_2\sin x\). With \(y(0) = 0,\ y(\pi) = 1\) there is no solution (\(y(0) = 0\) forces \(y = c_2\sin x\), which vanishes at \(\pi\)). With \(y(0) = 0,\ y(\pi) = 0\), every \(c_2\sin x\) works.

Definition

An eigenvalue problem asks for the values of \(\lambda\) (eigenvalues) for which a homogeneous BVP such as \(y'' + \lambda y = 0\), \(y(0) = 0\), \(y(L) = 0\) has nontrivial solutions (eigenfunctions).

Example 9.1

Find all eigenvalues and eigenfunctions of \(y'' + \lambda y = 0\), \(y(0) = 0\), \(y(L) = 0\).

Show solution

\(\lambda = -\mu^2 \lt 0\): \(y = c_1\cosh\mu x + c_2\sinh\mu x\). \(y(0) = c_1 = 0\); \(y(L) = c_2\sinh\mu L = 0\) forces \(c_2 = 0\) since \(\sinh\mu L \neq 0\). Only the trivial solution.

\(\lambda = 0\): \(y = c_1 + c_2x\); both conditions give \(c_1 = c_2 = 0\).

\(\lambda = \mu^2 \gt 0\): \(y = c_1\cos\mu x + c_2\sin\mu x\). \(y(0) = c_1 = 0\). \(y(L) = c_2\sin\mu L = 0\); for \(c_2 \neq 0\) need \(\mu L = n\pi\).

\[ \lambda_n = \left(\frac{n\pi}{L}\right)^2, \qquad y_n(x) = \sin\frac{n\pi x}{L}, \qquad n = 1, 2, 3, \ldots \]

These are the standing-wave shapes of a string fixed at both ends. With \(y'(0) = y'(L) = 0\) instead, the same analysis gives \(\lambda_n = (n\pi/L)^2\) for \(n = 0, 1, 2, \ldots\) with eigenfunctions \(\cos(n\pi x/L)\), including the constant \(n = 0\) mode.

9.2 Fourier series

Definition

For \(f\) defined on \([-L, L]\) (or \(2L\)-periodic), the Fourier series is

\[ f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty\left(a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\right). \]

Deriving the coefficients from orthogonality. For integers \(m, n \ge 1\):

\[ \int_{-L}^{L}\cos\frac{m\pi x}{L}\cos\frac{n\pi x}{L}\,dx = \int_{-L}^{L}\sin\frac{m\pi x}{L}\sin\frac{n\pi x}{L}\,dx = \begin{cases} L, & m = n \\ 0, & m \neq n \end{cases}, \qquad \int_{-L}^{L}\cos\frac{m\pi x}{L}\sin\frac{n\pi x}{L}\,dx = 0. \]

(Use product-to-sum identities; e.g. \(\cos A\cos B = \frac12[\cos(A - B) + \cos(A + B)]\), and a full-period integral of a nonconstant cosine is zero.) Now multiply the series by \(\cos(m\pi x/L)\) and integrate over \([-L, L]\), assuming term-by-term integration is allowed. Every term vanishes except the \(n = m\) cosine term, which contributes \(a_mL\). So \(a_m = \frac1L\int f\cos(m\pi x/L)\,dx\). The same move with \(\sin\) gives \(b_m\). Integrating the series directly (against \(1\)) gives \(\int f = a_0L\), which is why the constant term is written \(a_0/2\): it makes the \(a_n\) formula also valid for \(n = 0\).

Euler–Fourier formulas

\[ a_n = \frac1L\int_{-L}^{L}f(x)\cos\frac{n\pi x}{L}\,dx \ (n \ge 0), \qquad b_n = \frac1L\int_{-L}^{L}f(x)\sin\frac{n\pi x}{L}\,dx \ (n \ge 1). \]

Theorem (convergence)

If \(f\) and \(f'\) are piecewise continuous on \([-L, L)\) and \(f\) is extended to be \(2L\)-periodic, the Fourier series converges to \(f(x)\) at every point where \(f\) is continuous, and to the average \(\frac12\left[f(x^+) + f(x^-)\right]\) at every jump.

Study tip

Useful facts: \(\cos n\pi = (-1)^n\), \(\sin n\pi = 0\), and \(\int x\cos kx\,dx = \frac{x\sin kx}{k} + \frac{\cos kx}{k^2}\), \(\int x\sin kx\,dx = -\frac{x\cos kx}{k} + \frac{\sin kx}{k^2}\). Decay rate tells you smoothness: a function with jumps has coefficients falling like \(1/n\); a continuous function with corners, like \(1/n^2\). Near a jump, partial sums overshoot by about 9% of the jump no matter how many terms you take (the Gibbs phenomenon).

Example 9.2 (square wave)

Find the Fourier series of \(f(x) = -1\) for \(-\pi \lt x \lt 0\), \(f(x) = 1\) for \(0 \lt x \lt \pi\), extended \(2\pi\)-periodically.

Show solution

\(f\) is odd, so all \(a_n = 0\) (odd times even integrates to zero). With \(L = \pi\):

\[ b_n = \frac1\pi\int_{-\pi}^{\pi}f\sin nx\,dx = \frac2\pi\int_0^\pi\sin nx\,dx = \frac{2}{n\pi}\left(1 - \cos n\pi\right) = \begin{cases} \dfrac{4}{n\pi}, & n \text{ odd} \\ 0, & n \text{ even} \end{cases} \] \[ f(x) = \frac4\pi\left(\sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5} + \cdots\right). \]

At \(x = 0\) the series gives 0, the average of \(-1\) and \(1\), as the theorem says. EE reading: a square wave contains only odd harmonics, with amplitudes falling as \(1/n\).

Example 9.3 (triangle wave)

Find the Fourier series of \(f(x) = |x|\) on \([-\pi, \pi]\) and deduce \(\sum_{n \text{ odd}} 1/n^2\).

Show solution

\(f\) is even, so \(b_n = 0\). \(a_0 = \frac2\pi\int_0^\pi x\,dx = \pi\). For \(n \ge 1\):

\[ a_n = \frac2\pi\int_0^\pi x\cos nx\,dx = \frac2\pi\left[\frac{x\sin nx}{n} + \frac{\cos nx}{n^2}\right]_0^\pi = \frac{2}{\pi n^2}\left((-1)^n - 1\right), \]

which is \(-\dfrac{4}{\pi n^2}\) for odd \(n\) and 0 for even \(n\).

\[ |x| = \frac\pi2 - \frac4\pi\left(\cos x + \frac{\cos 3x}{9} + \frac{\cos 5x}{25} + \cdots\right). \]

\(f\) is continuous, so at \(x = 0\): \(0 = \frac\pi2 - \frac4\pi\sum_{n\text{ odd}}\frac1{n^2}\), hence \(\displaystyle\sum_{n \text{ odd}}\frac{1}{n^2} = \frac{\pi^2}{8}\).

9.3 Even and odd functions; half-range expansions

Symmetry shortcuts

If \(f\) is even: \(b_n = 0\), \(a_n = \frac2L\int_0^L f\cos\frac{n\pi x}{L}\,dx\) (cosine series).
If \(f\) is odd: \(a_n = 0\), \(b_n = \frac2L\int_0^L f\sin\frac{n\pi x}{L}\,dx\) (sine series).

A function given only on \(0 \lt x \lt L\) (a rod, a string) can be extended to \((-L, L)\) either way:

  • Odd extension \(\Rightarrow\) Fourier sine series. Natural when the boundary conditions are \(u = 0\) at both ends (Dirichlet).
  • Even extension \(\Rightarrow\) Fourier cosine series. Natural for \(u_x = 0\) at both ends (Neumann, insulated).

Let the boundary conditions choose the extension: they fix the eigenfunctions, and the eigenfunctions fix the series.

Example 9.4

Find the Fourier sine series of \(f(x) = 1\) on \(0 \lt x \lt L\).

Show solution \[ b_n = \frac2L\int_0^L\sin\frac{n\pi x}{L}\,dx = \frac2L\cdot\frac{L}{n\pi}\left[-\cos\frac{n\pi x}{L}\right]_0^L = \frac{2}{n\pi}\left(1 - (-1)^n\right). \]

So \(b_n = \dfrac{4}{n\pi}\) for odd \(n\), 0 for even \(n\): \(1 = \dfrac4\pi\displaystyle\sum_{n\text{ odd}}\frac1n\sin\frac{n\pi x}{L}\) on \(0 \lt x \lt L\). (The odd extension of 1 is the square wave of Example 9.2, rescaled.)

9.4 The heat equation

The problem

Temperature \(u(x,t)\) in a rod \(0 \le x \le L\) with diffusivity \(\alpha^2\), ends held at 0, initial profile \(f\):

\[ u_t = \alpha^2u_{xx}, \qquad u(0,t) = u(L,t) = 0, \qquad u(x,0) = f(x). \]

Separation of variables. Try \(u = X(x)T(t)\). Then \(XT' = \alpha^2X''T\), so

\[ \frac{X''}{X} = \frac{T'}{\alpha^2T} = -\lambda. \]

The left side depends only on \(x\) and the middle only on \(t\), so both equal a constant. The boundary conditions give \(X(0) = X(L) = 0\): Example 9.1, so \(\lambda_n = (n\pi/L)^2\), \(X_n = \sin(n\pi x/L)\). Then \(T' = -\alpha^2\lambda_nT\) gives \(T_n = e^{-n^2\pi^2\alpha^2t/L^2}\). Superpose and match \(t = 0\):

Heat equation solution (Dirichlet ends)

\[ u(x,t) = \sum_{n=1}^\infty b_n\,e^{-n^2\pi^2\alpha^2t/L^2}\sin\frac{n\pi x}{L}, \qquad b_n = \frac2L\int_0^Lf(x)\sin\frac{n\pi x}{L}\,dx. \]

Higher modes decay like \(e^{-n^2(\cdots)t}\), much faster than the first, so after a short time \(u\) looks like a single sine hump decaying exponentially. Diffusion smooths everything.

Nonzero boundary temperatures

If \(u(0,t) = T_1\), \(u(L,t) = T_2\), first find the steady state \(v(x) = T_1 + (T_2 - T_1)\frac{x}{L}\) (solves \(v'' = 0\) with those ends). Then \(w = u - v\) solves the problem above with zero ends and initial data \(f(x) - v(x)\). Insulated ends (\(u_x = 0\)) give a cosine series instead, and \(u \to a_0/2\), the average initial temperature, since heat can't escape.

Example 9.5

A rod with \(L = 1\) and \(\alpha^2 = 1\) is initially at uniform temperature 50, and both ends are suddenly held at 0. Find \(u(x,t)\) and estimate \(u(\tfrac12, 0.1)\).

Show solution

By Example 9.4 scaled by 50: \(b_n = \dfrac{200}{n\pi}\) for odd \(n\), 0 for even.

\[ u(x,t) = \frac{200}{\pi}\sum_{n\text{ odd}}\frac1n\,e^{-n^2\pi^2t}\sin n\pi x. \]

At \(x = \tfrac12,\ t = 0.1\): the \(n = 1\) term is \(\frac{200}{\pi}e^{-0.987} \approx 63.66 \times 0.373 \approx 23.7\). The \(n = 3\) term is \(\frac{200}{3\pi}e^{-0.9\pi^2}\sin\frac{3\pi}{2} \approx -21.2 \times 0.00014 \approx -0.003\). So \(u \approx 23.7\): one term already suffices.

9.5 The wave equation

The problem

A string of length \(L\) fixed at both ends, wave speed \(a = \sqrt{T/\rho}\) (tension over linear density):

\[ u_{tt} = a^2u_{xx}, \quad u(0,t) = u(L,t) = 0, \quad u(x,0) = f(x), \quad u_t(x,0) = g(x). \]

Separation gives the same \(X_n = \sin(n\pi x/L)\), but now \(T'' + \lambda_na^2T = 0\) is an oscillator with frequency \(\omega_n = n\pi a/L\). Each term is a normal mode (standing wave).

Wave equation solution (fixed ends)

\[ u(x,t) = \sum_{n=1}^\infty\left(b_n\cos\frac{n\pi at}{L} + c_n\sin\frac{n\pi at}{L}\right)\sin\frac{n\pi x}{L}, \] \[ b_n = \frac2L\int_0^Lf\sin\frac{n\pi x}{L}\,dx, \qquad \frac{n\pi a}{L}\,c_n = \frac2L\int_0^Lg\sin\frac{n\pi x}{L}\,dx. \]

Mode frequencies \(f_n = \dfrac{na}{2L}\) are integer multiples of the fundamental: the harmonic series of a string instrument. Unlike heat, nothing decays; the energy just sloshes between modes' kinetic and potential forms. Equivalently (d'Alembert), with \(g = 0\), \(u = \frac12\left[F(x - at) + F(x + at)\right]\) where \(F\) is the odd \(2L\)-periodic extension of \(f\): two copies of the initial shape travelling in opposite directions.

Example 9.6

Solve \(u_{tt} = 4u_{xx}\) on \(0 \lt x \lt 1\) with fixed ends, \(u(x,0) = \sin\pi x + \tfrac12\sin 3\pi x\), \(u_t(x,0) = 0\).

Show solution

\(a = 2\), \(L = 1\). The initial shape is already a sine series: \(b_1 = 1\), \(b_3 = \tfrac12\), others zero. All \(c_n = 0\) since \(g = 0\).

\[ u(x,t) = \sin\pi x\,\cos 2\pi t + \tfrac12\sin 3\pi x\,\cos 6\pi t. \]

Check: \(u_{tt} = -4\pi^2\sin\pi x\cos 2\pi t - 18\pi^2\sin 3\pi x\cos 6\pi t\) and \(4u_{xx} = 4\left(-\pi^2\sin\pi x\cos 2\pi t - \tfrac92\pi^2\sin 3\pi x\cos 6\pi t\right)\), equal. \(\checkmark\)

9.6 Laplace's equation

\(u_{xx} + u_{yy} = 0\) describes steady states: equilibrium temperature, electrostatic potential in a charge-free region, ideal fluid flow. Solutions (harmonic functions) are as smooth as possible, and each value is the average of the values on any circle around it. On a rectangle, impose the nonzero data on one side at a time and add the results.

Rectangle \(0 \lt x \lt a,\ 0 \lt y \lt b\), with \(u = 0\) on three sides and \(u(x, b) = f(x)\)

\[ u(x,y) = \sum_{n=1}^\infty c_n\sinh\frac{n\pi y}{a}\sin\frac{n\pi x}{a}, \qquad c_n\sinh\frac{n\pi b}{a} = \frac2a\int_0^af(x)\sin\frac{n\pi x}{a}\,dx. \]

(From \(X'' + \lambda X = 0\) with \(X(0) = X(a) = 0\), and \(Y'' - \lambda Y = 0\) with \(Y(0) = 0\).)

Example 9.7

Find the potential in the square \(0 \lt x, y \lt \pi\) with \(u = 0\) on three sides and \(u(x, \pi) = \sin 2x\).

Show solution

The boundary data is a single mode, \(n = 2\). So \(c_2\sinh 2\pi = 1\) and all other \(c_n = 0\):

\[ u(x,y) = \frac{\sinh 2y}{\sinh 2\pi}\sin 2x. \]

Check: \(u_{xx} = -4u\), \(u_{yy} = 4u\), sum zero; \(u = 0\) at \(x = 0, \pi\) and \(y = 0\); \(u(x,\pi) = \sin 2x\). \(\checkmark\)

    Answer

  2. Find the Fourier series of \(f(x) = x\) on \((-\pi, \pi)\).
    Answer

    Odd: \(b_n = \frac2\pi\int_0^\pi x\sin nx\,dx = \frac{2(-1)^{n+1}}{n}\). \(x = 2\left(\sin x - \frac{\sin 2x}{2} + \frac{\sin 3x}{3} - \cdots\right)\).

  3. Solve \(u_t = 4u_{xx}\) on \(0 \lt x \lt \pi\), \(u(0,t) = u(\pi,t) = 0\), \(u(x,0) = 3\sin 2x - \sin 5x\).
    Answer

    Decay rate for mode \(n\) is \(\alpha^2n^2 = 4n^2\): \(u = 3e^{-16t}\sin 2x - e^{-100t}\sin 5x\).

  4. A rod of length 2 has ends held at 20 and 80. Find the steady-state temperature, and say what problem the transient \(w = u - v\) satisfies.
    Answer

    \(v(x) = 20 + 30x\). \(w\) solves the heat equation with \(w(0,t) = w(2,t) = 0\) and \(w(x,0) = f(x) - 20 - 30x\).

  5. Solve \(u_{tt} = 9u_{xx}\) on \(0 \lt x \lt \pi\) with fixed ends, \(u(x,0) = 0\), \(u_t(x,0) = \sin x + 2\sin 3x\).
    Answer

    \(a = 3\), \(\omega_n = 3n\). \(3c_1 = 1\), \(9c_3 = 2\): \(u = \tfrac13\sin 3t\sin x + \tfrac29\sin 9t\sin 3x\).

  6. What does the Fourier series of the square wave in Example 9.2 converge to at \(x = \pi\)? At \(x = \pi/2\), and what series identity results?
    Answer

    At \(x = \pi\) (a jump from 1 to \(-1\)): 0. At \(x = \pi/2\): \(1 = \frac4\pi\left(1 - \frac13 + \frac15 - \cdots\right)\), so \(1 - \frac13 + \frac15 - \cdots = \frac\pi4\) (Leibniz).
